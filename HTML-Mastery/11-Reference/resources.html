1 Official Specifications

The source of truth. When in doubt, the spec is right.

WHATWG HTML Living Standard

html.spec.whatwg.org

The canonical HTML specification. Continuously updated — no version numbers, just "the latest". If you want to know exactly how an element behaves, this is the answer.

OfficialFree

W3C HTML

w3.org/html

The W3C's HTML snapshot spec. Note: WHATWG is now the authoritative source — W3C mirrors the Living Standard.

OfficialFree

W3C ARIA Specification

w3.org/TR/wai-aria

The Accessible Rich Internet Applications spec. Defines all the roles, states, and properties. Required reading for accessibility work.

OfficialFree

WCAG 2.2

w3.org/TR/WCAG22

Web Content Accessibility Guidelines 2.2, the current W3C recommendation. The legal baseline in most jurisdictions. Read it once; refer back forever.

OfficialFree

RFC 3986: URL Syntax

rfc-editor.org/rfc/rfc3986

The IETF spec defining URLs. Essential for understanding href, query strings, fragments, and encoding.

OfficialFree

Schema.org

schema.org

The structured data vocabulary maintained by Google, Microsoft, Yahoo, and Yandex. Reference for Article, Product, Event, FAQPage, and dozens more types.

OfficialFree
Pro Tip The spec is dense and written for implementers (browser makers). Use it as a reference, not a tutorial. MDN is friendlier for daily learning; the spec is the tiebreaker when MDN is unclear.

2 Learning Platforms

Where to actually learn HTML. Pick one and finish it.

MDN Web Docs

developer.mozilla.org

The single best HTML reference on the internet. Maintained by Mozilla with community contributions. Bookmark this. Every element page has examples, browser support, and spec links.

Free

MDN Learn Web Development

developer.mozilla.org/en-US/docs/Learn

Structured learning path from absolute beginner to working developer. Free, comprehensive, beginner-friendly. Start here if you're new.

Free

web.dev

web.dev

Google's web platform education site. Excellent deep dives on performance, Core Web Vitals, Lighthouse, and modern HTML features. The "Learn" courses are superb.

Free

freeCodeCamp

freecodecamp.org

Free, project-based curriculum. The "Responsive Web Design" certification takes you from HTML basics to a portfolio of 5 projects. Great for hands-on learners.

Free

The Odin Project

theodinproject.com

Open-source full-stack curriculum. The "Foundations" path covers HTML, CSS, and JS with real projects. Strong community on Discord.

Free

W3Schools

w3schools.com

Tutorials with live "Try it" editors. Faster for quick lookups than MDN, though sometimes less precise. Useful for beginners; verify anything advanced against MDN.

Free

HTML Dog

htmldog.com

Old but still excellent tutorials. Beginner, intermediate, and advanced tracks. Concise and well-written.

Free

Frontend Masters

frontendmasters.com

Paid video courses from industry experts. Look for courses by Estelle Weyl (HTML), Jen Kramer, and Brian Holt. High production quality, deep content.

Paid

Codrops

tympanus.net/codrops

Cutting-edge UI experiments and tutorials. Excellent reference for modern CSS and creative HTML patterns. The "Playground" section is full of inspiration.

Free

W3C Web Education

w3.org/community/webed

The W3C's community group for web education. Includes curriculum guidance and accessibility-focused resources.

OfficialFree

3 Tools & Extensions

The tools that make writing HTML faster and validating it possible.

Validators

W3C Markup Validator

validator.w3.org

The original HTML validator. Paste HTML, upload a file, or give a URL. Errors, warnings, and info-level issues. Always validate before shipping.

OfficialFree

Nu HTML Checker

validator.w3.org/nu

The newer W3C validator using the HTML Living Standard. More accurate than the legacy validator. Also available as a command-line tool (v.Nu).

OfficialFree

WAVE Accessibility Evaluator

wave.webaim.org

WebAIM's accessibility checker. Visual overlay showing errors, alerts, and structural elements on any page. Browser extension also available.

Free

axe DevTools

deque.com/axe/devtools

The most accurate accessibility testing tool. Browser extension and CLI. Free for development; paid for enterprise CI integration.

Free tier

Browser Dev Tools

Chrome DevTools

developer.chrome.com/docs/devtools

The most comprehensive browser dev tools. Elements panel, Network, Performance, Lighthouse, Application, and Accessibility tabs. Press F12.

Free

Firefox Developer Tools

firefox-source-docs.mozilla.org/devtools-user

Firefox's dev tools, especially strong in CSS inspection (font inspector, color picker, flexbox/grid overlays). Accessibility panel is excellent.

Free

Safari Web Inspector

developer.apple.com/safari/tools

Enable in Safari → Settings → Advanced → Show Develop menu. Essential for testing on iOS and macOS-specific behaviors.

Free

5 Books

Books for the long road. Buy them in print; reference them forever.

HTML & CSS: Design and Build Websites

Jon Duckett · Wiley · 2011

The most beautiful programming book ever printed. Full-color, generous layout, beginner-friendly. Still the best introduction to HTML and CSS for visual learners.

Paid

JavaScript & jQuery

Jon Duckett · Wiley · 2014

The companion volume to Duckett's HTML & CSS. Same beautiful design. The DOM manipulation chapters are particularly clear.

Paid

HTML5: Up and Running

Mark Pilgrim · O'Reilly · 2010

Old but a classic. Read free online at diveintohtml5.info. The history chapters are still the best explanation of why HTML5 is what it is.

Free online

Designing for the Web

Mark Boulton · 2009

Free online. Pre-HTML5 but the typography and grid principles are timeless. Especially good for designers moving into web.

Free online

Accessibility for Everyone

Laura Kalbag · A Book Apart · 2017

Short, practical, humane introduction to web accessibility. The book to read after you've finished your first website.

Paid

Inclusive Components

Heydon Pickering · A Book Apart · 2019

Patterns for accessible UI: tooltips, dialogs, menus, data tables. Each pattern explains the accessibility reasoning. Read free online at inclusive-components.design.

Free online

Web Performance in Action

Jeremy Wagner · Manning · 2017

Deep dive on web performance: critical rendering path, image optimization, font loading, JavaScript deferral. Slightly dated but the principles hold.

Paid

Resilient Web Design

Jeremy Keith · A Book Apart · 2017

Free online at resilientwebdesign.com. A short, philosophical book about progressive enhancement and why HTML is the most resilient layer of the web. Read this once a year.

Free online

8 How to use this list

This list is long. Don't try to consume it all at once. Here's a path:

StagePickWhy
Beginner (0–3 months)MDN Learn + freeCodeCampStructured, free, project-based. Builds muscle memory.
Beginner+Jon Duckett's HTML & CSSBeautiful book that makes the abstract concrete.
Intermediate (3–12 months)Resilient Web Design + Inclusive ComponentsMental models for the why behind the what.
Intermediate+Smashing Magazine + CSS-Tricks newslettersSteady stream of new techniques.
Advanced (1+ years)WHATWG HTML Living Standard + W3C ARIA specRead the source. Become the source.
AlwaysW3C Validator + Lighthouse on every projectThe habit that separates pros from amateurs.
Pro Tip The single most valuable habit is this: validate every page before you ship it. Run it through the W3C validator, fix every error, and run Lighthouse. Most "bugs" are HTML mistakes the validator would have caught. Five minutes of validation saves five hours of debugging.
A Note on Listicles We deliberately excluded "Top 10 HTML Tricks You Didn't Know" articles and similar clickbait. They're written for engagement, not learning. The resources here are written by people who use this stuff daily. Bookmark the spec, MDN, and one newsletter. That's all you need.
