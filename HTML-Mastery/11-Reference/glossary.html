Major topics

  • Semantic HTML
  • Accessibility / ARIA

A

Accessibilitynoun

The practice of building websites that people with disabilities can use — keyboard-only users, screen reader users, people with low vision, color blindness, motor impairments, and cognitive differences. Abbreviated a11y (11 letters between a and y).

See also: ARIA, WCAG, Semantic HTML

Anchornoun

The <a> element — a hyperlink. Despite the name, name attributes for in-page anchors are obsolete; use id on the target element and link to #id.

ARIAnoun

Accessible Rich Internet Applications. A W3C spec adding roles, states, and properties to HTML for widgets that have no native equivalent (comboboxes, tree views, live regions). The first rule: don't use ARIA if a native element exists.

See also: Accessibility, WAI-ARIA

Attributenoun

A name/value pair on an HTML element that configures its behavior or provides metadata. Written as name="value" inside the opening tag. Boolean attributes (disabled, required) need no value.

See also: Global attribute, Boolean attribute

ARIA rolenoun

The role attribute tells assistive tech what an element does. Three categories: landmark (banner, main), document (heading, list), and widget (tab, combobox).

Asyncadjective

The async attribute on <script> tells the browser to download the script in parallel with HTML parsing, then execute it as soon as it's ready — out of DOM order. Useful for independent scripts like analytics.

See also: Defer

Autofillnoun

The browser's ability to fill form fields automatically using stored data (name, address, credit card). Triggered by the autocomplete attribute with specific tokens like name, email, street-address.

B

Block elementnoun

An element that occupies the full width of its container by default, starting on a new line. Examples: <div>, <p>, <section>. CSS controls this — "block" is the default display value.

See also: Inline element

Boolean attributenoun

An attribute whose presence alone is meaningful — the value is irrelevant. Examples: disabled, required, checked, readonly, multiple. Writing disabled="false" still enables the disabled state.

Browser dev toolsnoun

Built-in browser developer tools (F12 / Cmd+Opt+I). Includes Elements panel (DOM inspection), Console, Network, Performance, Application, and Accessibility panels. Essential for debugging HTML, CSS, JS, and performance.

C

Canvasnoun

The <canvas> element — a resolution-dependent bitmap drawing surface manipulated via JavaScript 2D or WebGL context. Used for games, data visualization, image editing. Unlike SVG, the drawn pixels are not part of the DOM.

See also: SVG

Categorical contentnoun

The HTML spec groups elements into seven content categories: metadata, flow, sectioning, heading, phrasing, embedded, and interactive. An element can belong to multiple categories; this determines where it can be placed.

Cild elementnoun

An element nested inside another (its parent). The DOM forms a tree of parents and children.

See also: DOM, Nesting

Closed shadow DOMnoun

A shadow root created with attachShadow({ mode: 'closed' }). External JavaScript cannot access its internal nodes via shadowRoot. Useful for security-sensitive widgets but rarely needed.

See also: Shadow DOM, Open shadow DOM

Constraint validationnoun

The native HTML5 form validation API. The browser checks fields against constraints (required, type="email", pattern, min/max) and shows native error UI. JavaScript can hook into it via the ValidityState object.

See also: Form validation

Content categorynoun

See Categorical content.

Crawlverb

The process by which a search engine bot downloads and parses pages. Pages it can't crawl (noindex, robots.txt disallow, behind login) won't appear in search results.

See also: SEO

Critical rendering pathnoun

The sequence of steps the browser takes to render a page: HTML → DOM, CSS → CSSOM, combined into render tree, then layout → paint → composite. Optimizing this path (smaller HTML, deferred JS, inlined critical CSS) is the foundation of web performance.

Custom elementnoun

A user-defined HTML element registered via customElements.define(). Names must contain a hyphen (e.g. <my-button>). Two kinds: autonomous (extends HTMLElement) and customized built-in (extends HTMLButtonElement, used via is="my-button").

See also: Web component, Shadow DOM

CSSOMnoun

CSS Object Model. The browser's in-memory tree representation of parsed CSS, analogous to the DOM for HTML. The render tree combines DOM + CSSOM nodes that are visible.

D

Data attributenoun

Any attribute starting with data-. Used to store custom data on elements for JavaScript to read via the dataset property. Example: data-user-id="42" becomes element.dataset.userId.

Deferadjective

The defer attribute on <script> tells the browser to download in parallel but execute in DOM order, after HTML parsing completes. Default choice for non-urgent scripts. Modules are implicitly deferred.

See also: Async

Deprecatedadjective

An element or attribute that the spec marks as "do not use" but browsers still support for backwards compatibility. Examples: <center>, <font>, the bgcolor attribute. May be removed eventually.

Dialognoun

The <dialog> element — a native modal or non-modal popup. show() for non-modal, showModal() for modal (with backdrop, focus trap, ESC handling). The ::backdrop pseudo-element styles the overlay.

Discnoun

The default bullet style for unordered lists. Override via list-style-type CSS.

Distributed contentnoun

Children of a host element that are projected into a shadow DOM tree via <slot>. The original nodes stay in the light DOM; only their rendering moves into the shadow tree.

See also: Slot, Shadow DOM

DOCTYPEnoun

The first line of an HTML document: <!DOCTYPE html>. Tells the browser to use standards mode. Without it, browsers enter quirks mode where box model and other behaviors differ from the spec.

DOMnoun

Document Object Model. The browser's in-memory tree representation of the parsed HTML, accessible via JavaScript (document.querySelector, etc.). Each node is an Element, Text node, Comment, or Document.

Drag and dropnoun

The native HTML drag-and-drop API: draggable attribute, dragstart/dragover/drop events, and the dataTransfer object. Doesn't fire on touch devices — use Pointer Events for cross-platform.

E

Edgenoun

Microsoft Edge, the default Windows browser since 2020. Chromium-based (shares engine with Chrome). Not to be confused with legacy EdgeHTML Edge (2015–2020), which is deprecated.

Elementnoun

A single node in HTML, defined by a tag. Example: <p>Hello</p> is a paragraph element. The opening tag, content, and closing tag together form the element. Void elements (e.g. <img>) have no closing tag.

See also: Tag, Void element

Embedded contentnoun

A content category for elements that import external resources: <img>, <iframe>, <video>, <audio>, <object>, <embed>, <canvas>, <svg>, <math>.

Empty elementnoun

Alternative name for void element. An element with no content and no closing tag, like <br> or <hr>.

F

Facadenoun

A pattern for third-party embeds (YouTube, maps): show a static preview image and only load the real embed when the user clicks. Drastically improves load performance.

Fieldsetnoun

The <fieldset> element groups related form controls. Always pair with a <legend> for an accessible group label. Screen readers announce the legend when entering the fieldset.

Flow contentnoun

The largest content category — most elements that can appear in <body>. Includes headings, paragraphs, lists, sections, articles, etc.

Focus trapnoun

A pattern for modal dialogs: keyboard focus cycles only within the dialog until it closes. Implemented with tabindex="-1" on focusable elements outside, or by listening for Tab and redirecting focus.

Form validationnoun

The browser's built-in checking of form fields before submission. Triggers when the user clicks submit. Controlled by attributes (required, pattern, min/max/step, minlength/maxlength) and the novalidate form attribute.

See also: Constraint validation

Fragment identifiernoun

The #id part of a URL that scrolls the page to the matching element. Example: example.com/page#section-2 jumps to id="section-2". Used heavily in tables of contents.

G

Global attributenoun

An attribute that can appear on any HTML element. Examples: id, class, style, title, lang, tabindex, hidden, data-*, aria-*.

H

Headingnoun

An <h1> through <h6> element. Headings form the page outline that screen reader users navigate. Use exactly one h1 per page, and don't skip levels (h1 → h3 is wrong).

Host elementnoun

The custom element that owns a shadow DOM tree. Inside the shadow tree, the :host CSS selector matches it.

hrefattribute

Hyperlink Reference. The URL an <a> points to. Without href, the element is not a link — it becomes inert text styled like a link.

hreflangattribute

Declares the language of the page a link points to. Used in <link rel="alternate"> for internationalization: one link per language version, plus x-default.

HTML entitynoun

A special character encoded for HTML. Examples: &amp; for &, &lt; for <, &copy; for ©, &mdash; for —. Always escape <, >, & in code samples.

HTTPnoun

HyperText Transfer Protocol. The application-layer protocol HTML travels over. Modern web uses HTTPS (encrypted via TLS). Browsers speak HTTP/2 or HTTP/3 by default.

I

Iframenoun

The <iframe> element — an inline frame that embeds another document. Always include a title for accessibility, and use sandbox for untrusted content.

Inline elementnoun

An element that doesn't break the line of text — flows inline like a word. Examples: <span>, <a>, <em>, <strong>, <code>.

See also: Block element

Inertadjective

The inert attribute makes an element and all its descendants non-interactive: not focusable, not clickable, removed from accessibility tree. Used for content behind a modal overlay.

Input modenoun

The inputmode attribute hints which mobile keyboard to show: numeric, decimal, tel, email, url, search. Different from type — you can have type="text" with inputmode="numeric".

Intersection Observernoun

A JavaScript API that fires a callback when an element enters or leaves the viewport. Used for lazy loading, infinite scroll, and triggering animations. Replaces scroll-event listeners (which are expensive).

J

JSON-LDnoun

JavaScript Object Notation for Linked Data. The recommended way to add Schema.org structured data to a page — a <script type="application/ld+json"> block. Google uses it for rich results (FAQs, recipes, products).

See also: Structured data

K

Keyboard navigationnoun

Using the keyboard (Tab, Shift+Tab, Enter, Space, arrows, ESC) to navigate and operate a page. Required for accessibility — many users cannot use a mouse. Test by tabbing through your page: every interactive element should have a visible focus ring.

kbdelement

The <kbd> element represents keyboard input: <kbd>Ctrl</kbd> + <kbd>S</kbd>. Visually monospace by default. Pair with <samp> for program output.

L

Landmarknoun

An HTML element that maps to an ARIA landmark role: <header> (banner), <nav> (navigation), <main> (main), <aside> (complementary), <footer> (contentinfo), <section> (region), <form> (form), <search> (search). Screen readers can jump between them.

Lazy loadingnoun

Deferring the fetch of off-screen images and iframes until they're about to enter the viewport. Native via loading="lazy". Reduces initial page weight and bandwidth.

Light DOMnoun

The regular DOM tree — children of an element that are not in any shadow root. When a custom element has a shadow root, its light DOM children get distributed into slots.

See also: Shadow DOM

Living Standardnoun

The HTML specification maintained by WHATWG. Unlike versioned specs (HTML 4.01, HTML5), it's a continuous document with no version numbers — features ship as they're ready. The canonical URL: html.spec.whatwg.org.

M

Manifestnoun

A JSON file (manifest.webmanifest) referenced via <link rel="manifest"> that lets users install your site as a PWA. Contains name, icons, theme color, display mode.

Metadatanoun

Data about the page — title, description, author, charset, viewport, OG tags, structured data. Lives in <head>, invisible to users but critical for browsers, search engines, and social platforms.

Microdatanoun

An older syntax for embedding structured data via itemscope, itemtype, itemprop attributes on regular HTML elements. Largely replaced by JSON-LD, which is easier to maintain.

See also: Structured data, JSON-LD

Mobile-firstadjective

A design and CSS strategy: write styles for mobile screens first, then add media queries for larger screens. Forces focus on essential content. Google uses mobile-first indexing — the mobile version is the canonical one for SEO.

Modulenoun

ES modules — native JavaScript modules loaded via <script type="module">. Always deferred, run in strict mode, support import / export. Use modulepreload to fetch them early.

N

Namenoun

The accessible name of an element — what a screen reader announces. Derived from: aria-label > aria-labelledby > visible text > title attribute. Every interactive element needs one.

Nestingnoun

Placing one element inside another. Rules: block elements can contain inline; inline generally cannot contain block; some elements have specific nesting rules (e.g., <a> cannot contain another <a>).

Noscriptelement

The <noscript> element renders its content only when JavaScript is disabled. Use for graceful degradation messages or no-JS fallback content.

O

Open Graphnoun

The og:* meta tags (created by Facebook, now used everywhere) that control how a link preview appears when shared on social media: og:title, og:description, og:image, og:url, og:type.

Open shadow DOMnoun

A shadow root created with attachShadow({ mode: 'open' }). External JavaScript can access it via element.shadowRoot. The default and recommended mode for most components.

See also: Shadow DOM, Closed shadow DOM

P

Page outlinenoun

The structure formed by headings (h1–h6) on a page. Screen reader users navigate by it. Test by viewing the outline view (some browsers and tools can show it).

Phrasing contentnoun

A content category of inline elements: <a>, <span>, <em>, <strong>, <code>, etc. Can appear inside paragraphs and other phrasing elements.

Pictureelement

The <picture> element wraps <source> + <img> for art direction: serving different images based on viewport, format support, or resolution.

Popovernoun

The Popover API (HTML 2023+): the popover attribute makes an element a popover, popovertarget on a button toggles it. Native support for tooltips, menus, modals without JS. Light-dismiss (click outside) when popover="auto".

Preconnectnoun

A <link rel="preconnect"> hint that tells the browser to warm up a connection (DNS, TCP, TLS) to a third-party origin. Use for fonts, CDNs, APIs you'll fetch from soon.

Preloadnoun

A <link rel="preload" as="image"> hint that fetches a high-priority resource the page will need soon. Required as attribute. Use for the LCP image.

Prefetchnoun

A <link rel="prefetch"> hint that fetches a resource at low priority for the next navigation. Useful for the next page the user is likely to visit.

Q

Quirks modenoun

A non-standard rendering mode browsers enter when a page is missing the <!DOCTYPE html> declaration. Box model and other behaviors differ from spec. Always include the doctype.

See also: DOCTYPE

R

Render treenoun

The combination of DOM and CSSOM that contains only the visible elements (excludes display:none and elements inside <head>). The browser uses it to compute layout and paint pixels.

Requiredattribute

A boolean attribute that makes a form field mandatory. The browser blocks submission and shows an error if empty. Pair with aria-required="true" for older screen readers (modern ones respect the attribute).

Responsive imagesnoun

Serving different image files based on viewport size and pixel density. Implemented via srcset + sizes attributes (resolution switching) or <picture> + <source> (art direction).

Rolenoun

See ARIA role.

Root elementnoun

The <html> element — the top of every HTML document. Required. Has a lang attribute that sets the document's language for screen readers and translation tools.

Roving tabindexnoun

A pattern for composite widgets (toolbars, tablists, menus): only one child has tabindex="0", the rest have tabindex="-1". Arrow keys move focus between them. Reduces Tab stops for keyboard users.

S

Schema.orgnoun

A vocabulary of structured data types (Article, Product, Event, Recipe, FAQPage, HowTo, etc.) maintained by Google, Microsoft, Yahoo, and Yandex. Embedded in pages via JSON-LD, Microdata, or RDFa. Powers rich search results.

See also: Structured data, JSON-LD

Screen readernoun

Software that reads the page aloud (or outputs to a Braille display) for blind users. Examples: NVDA (Windows, free), JAWS (Windows, paid), VoiceOver (macOS/iOS), TalkBack (Android), Orca (Linux).

SEOnoun

Search Engine Optimization — practices that make a page rank higher in search results. Includes semantic HTML, descriptive titles and meta descriptions, structured data, fast page loads, mobile friendliness, and quality content.

Semantic HTMLnoun

Using HTML elements for their meaning, not their appearance. <button> for clickable actions (not <div onclick>), <nav> for navigation, <article> for self-contained content. Semantic HTML is the foundation of accessibility and SEO.

Shadow DOMnoun

An encapsulated DOM tree attached to an element via attachShadow(). Styles and IDs inside don't leak out; outside styles don't leak in. Foundation of reusable web components.

See also: Web component, Slot, Custom element

Slotnoun

The <slot> element inside a shadow DOM tree — a placeholder where light DOM children get projected. Named slots (name="header") match children with slot="header"; the default slot catches unmatched children.

Sourceelement

The <source> element — a void element providing alternative formats inside <picture> or alternative codecs inside <video>/<audio>. Browser picks the first one it supports.

Srcsetattribute

An attribute on <img> that lists image candidates at different widths: srcset="img-400.jpg 400w, img-800.jpg 800w". Browser picks the best one based on viewport and pixel density. Pair with sizes.

Structured datanoun

Machine-readable information about the page embedded in HTML — typically via JSON-LD using Schema.org vocabulary. Lets search engines show rich results: star ratings, event times, recipe ingredients, FAQ accordions.

See also: JSON-LD, Schema.org

SVGnoun

Scalable Vector Graphics — an XML-based format for vector images that scales crisply at any size. Can be embedded inline in HTML (<svg>) or as an image source (<img src="logo.svg">).

See also: Canvas

T

Tab ordernoun

The order in which elements receive focus when the user presses Tab. Defaults to DOM order. Modify with tabindex: positive values create explicit order (avoid), 0 includes in natural order, -1 removes from tab order.

Tablenoun

The <table> element — for tabular data only, never for layout. Use <caption>, <thead>/<tbody>/<tfoot>, and scope on <th> for accessibility.

Tagnoun

The markup delimiters that wrap an element's content: <p> is an opening tag, </p> is a closing tag. Together they form an element. Void elements have only an opening tag (<br>).

See also: Element, Void element

Templateelement

The <template> element — inert HTML that the browser parses but doesn't render. Clone its .content with JavaScript to stamp out repeated UI. Foundation of client-side rendering.

Titlenoun

(1) The <title> element in <head> — page title shown in the browser tab and search results. 50–60 chars ideal.
(2) The title attribute on any element — provides a tooltip on hover.

U

URLnoun

Uniform Resource Locator — the address of a web resource. Anatomy: scheme://host:port/path?query#fragment. Example: https://example.com/page?id=42#top.

User agentnoun

The software that fetches and renders HTML — typically a browser, but also crawlers (Googlebot), screen readers, and download tools. Identified by the User-Agent string, though this is being phased out for privacy.

V

ValidityStatenoun

A JavaScript object available on every form field via element.validity. Contains booleans: valueMissing, typeMismatch, patternMismatch, tooLong, rangeUnderflow, etc. Plus valid as a summary.

Viewportnoun

(1) The visible area of the page in the browser. (2) The <meta name="viewport"> tag — required for responsive mobile design. Without it, mobile browsers render at desktop width and zoom out.

Void elementnoun

An element with no content and no closing tag. The full list: <area>, <base>, <br>, <col>, <embed>, <hr>, <img>, <input>, <link>, <meta>, <param>, <source>, <track>, <wbr>.

W

WAI-ARIAnoun

Web Accessibility Initiative – Accessible Rich Internet Applications. The W3C working group that maintains the ARIA spec. Often shortened to "ARIA".

WCAGnoun

Web Content Accessibility Guidelines — the W3C standard for web accessibility. Current version: 2.2 (2023). Three conformance levels: A (minimum), AA (legal baseline in most jurisdictions), AAA (highest, not always achievable). Built on four principles: Perceivable, Operable, Understandable, Robust.

See also: Accessibility

Web componentnoun

A set of three native technologies for reusable UI: Custom Elements, Shadow DOM, and HTML Templates. Together they let you build framework-agnostic, encapsulated components. Used by YouTube, GitHub, Adobe, LinkedIn.

See also: Custom element, Shadow DOM, Template

WHATWGnoun

Web Hypertext Application Technology Working Group — the community that maintains the HTML Living Standard, plus Fetch, DOM, URL, and other specs. Formed in 2004 in response to slow W3C progress on HTML.

X

XHTMLnoun

HTML reformulated as XML (strict: all attributes quoted, all tags closed). Popular in the early 2000s, now mostly historical. HTML5 absorbed its discipline without requiring XML strictness.

X-defaultnoun

The hreflang="x-default" attribute on a <link rel="alternate"> declares the fallback page for users whose language isn't explicitly listed. Always include one per localized site.

Y

YouTube facadenoun

The most common facade pattern: show a thumbnail of a YouTube video with a play button, and only embed the actual <iframe> when the user clicks. Saves ~1MB of JavaScript on initial load.

See also: Facade

Z

Zero-width spacenoun

The Unicode character U+200B — invisible but marks a place where a line can break. Useful in long URLs or technical strings. HTML also has <wbr> for the same purpose.

Final notes

This glossary isn't exhaustive — the HTML spec has more — but it covers the vocabulary you'll meet on the road from beginner to expert. When you meet an unfamiliar term in the wild, come back here.

Pro Tip The best way to learn HTML vocabulary is to read the source of pages you admire. Right-click → View Source on any well-built site. You'll see these terms in context, which is worth more than any glossary.
