Section 2.3 · Quotations & Citations

The <blockquote> Element

The block-level quote. Used for long passages taken from another source. With the cite attribute, the <cite> child, and thoughtful CSS, a blockquote can become a powerful pull-quote, an academic citation, or a visual centerpiece.

1 What Is a Blockquote?

The <blockquote> element represents a section that is quoted from another source. It is a block-level element — by default it gets some left and right margin and indentation. Use it for longer quotations that span multiple lines or multiple paragraphs.

For short, inline quotations, use the <q> element instead (see the next page in this guide).

Info A general guideline: if the quote is short enough to fit naturally inside a paragraph (one or two sentences), use <q>. If it deserves its own visual block, use <blockquote>.

2 Basic Syntax

<blockquote>
  <p>
    The best way to predict the future is to invent it.
  </p>
</blockquote>

The best way to predict the future is to invent it.

The default browser styling is unglamorous — just left/right margin and italic font in some browsers. Real websites almost always override this with CSS.

Pro Tip Always wrap the actual quote text in a <p> tag inside the <blockquote>. The blockquote itself can hold multiple paragraphs, lists, or other block content — it is a flow container, not a text container.

3 The cite Attribute

The cite attribute on <blockquote> holds a URL pointing to the source document. It is machine-readable but not visible to users by default.

<blockquote cite="https://www.w3.org/TR/html/">
  <p>
    HTML is the World Wide Web's core markup language.
  </p>
</blockquote>

The cite attribute is great for SEO and for tools that want to follow the citation. But because it is invisible, you should usually also show the source visibly inside the quote using the <cite> element.

Common Mistake The cite attribute accepts only a URL. Do not put an author name, book title, or plain text in it. For visible attribution, use the <cite> element inside the blockquote.

4 Displaying the Source

To show the source visibly, place a <cite> element inside the blockquote (or after it). The <cite> element represents the title of the work being cited.

<blockquote cite="https://books.example.com/dune">
  <p>
    A beginning is the time for taking the most delicate care
    that the balances are correct.
  </p>
  <footer>
    — <cite>Dune</cite> by Frank Herbert, 1965
  </footer>
</blockquote>

A beginning is the time for taking the most delicate care that the balances are correct.

Dune by Frank Herbert, 1965
Pro Tip You can wrap the citation in a <footer> element inside the blockquote. This is semantic: the footer of a blockquote holds metadata about the quote, like the source and author.

5 Nested Quotes

When a blockquote itself contains a quote — either inline or another block — you can nest <q> or another <blockquote> inside it. The browser handles the typographic quote characters automatically.

<blockquote>
  <p>
    In his speech, Dr. King declared:
    <q>I have a dream that one day this nation will rise up
       and live out the true meaning of its creed.</q>
  </p>
</blockquote>

For deeply nested quotes, the browser alternates between double and single quote characters automatically:

<p>
  She said, <q>He told me, <q>I'll be there</q> yesterday</q>.
</p>

She said, "He told me, 'I'll be there' yesterday".

6 Styling with CSS

Almost no production website uses the default blockquote styling. Here are the most common patterns:

Left border with indent

blockquote {
  margin: 1.5em 0;
  padding: 8px 24px;
  border-left: 4px solid #2563eb;
  background: #f8fafc;
  color: #475569;
  font-style: italic;
}

blockquote p { margin: 0 0 0.5em; }
blockquote p:last-child { margin-bottom: 0; }

blockquote cite {
  display: block;
  margin-top: 12px;
  font-style: normal;
  font-weight: 600;
  color: #0f172a;
  font-size: 0.9em;
}
blockquote cite::before { content: "— "; }

Centered card with quote marks

blockquote.card {
  margin: 2em auto;
  max-width: 600px;
  padding: 32px 40px;
  background: #fff;
  border-radius: 12px;
  box-shadow: 0 10px 30px rgba(0,0,0,0.06);
  text-align: center;
  font-size: 1.15rem;
  line-height: 1.6;
  color: #0f172a;
}

blockquote.card::before {
  content: "\201C";  /* left double quote */
  font-family: Georgia, serif;
  font-size: 4rem;
  color: #2563eb;
  line-height: 0.5;
  display: block;
  margin-bottom: 8px;
}

Two-tone gradient border

blockquote.gradient {
  border: 0;
  border-left: 5px solid;
  border-image: linear-gradient(180deg, #2563eb, #7c3aed) 1;
  background: linear-gradient(90deg, #f0fdf4 0%, transparent 100%);
  padding: 16px 24px;
}

7 Pull-Quotes

A pull-quote is a large, visually striking excerpt from the article, used as a design element to break up long text and draw attention to a key insight. Pull-quotes are not technically citations of an external source — they quote from the article itself — but they use <blockquote> for the visual treatment.

<blockquote class="pull-quote">
  <p>The future of the web is being written by everyone, for everyone.</p>
</blockquote>

The future of the web is being written by everyone, for everyone.

Pro Tip For pull-quotes that duplicate text from the article, consider adding aria-hidden="true" or wrapping with role="presentation" so screen readers do not announce the same passage twice.

8 Accessibility

  • By default, <blockquote> has the implicit ARIA role of blockquote in newer accessibility APIs.
  • Some screen readers announce "blockquote" or "quoted" before reading the content.
  • The cite attribute (URL) is generally not announced — it is for machine consumption.
  • The visible <cite> element is announced as normal text.
Info If you use <blockquote> purely for visual styling (e.g. indenting a non-quote block), add role="presentation" or aria-hidden="true" to avoid confusing screen-reader users. Better yet, use a <div> with CSS for visual-only indentation.

Adding a visible "Quote:" label

blockquote::before {
  content: "Quote: ";
  font-weight: 600;
  color: var(--brand);
}

This pattern is overkill for most designs but useful in legal or academic contexts where the source distinction matters.

9 Real-World Examples

Academic citation

<blockquote cite="https://doi.org/10.1000/182">
  <p>
    The Semantic Web is not a separate Web but an extension of the
    current one, in which information is given well-defined meaning,
    better enabling computers and people to work in cooperation.
  </p>
  <footer>
    — Tim Berners-Lee, James Hendler, Ora Lassila,
    <cite>The Semantic Web</cite>, Scientific American, 2001.
    <a href="https://doi.org/10.1000/182">DOI: 10.1000/182</a>
  </footer>
</blockquote>

Customer testimonial

<figure class="testimonial">
  <blockquote cite="https://example.com/case-study">
    <p>
      Switching to Acme cut our deployment time by 60%.
      Our team ships features faster than ever.
    </p>
  </blockquote>
  <figcaption>
    — <strong>Jane Doe</strong>, CTO at StartUp Inc.
  </figcaption>
</figure>

News article excerpt

<article>
  <h1>City Council Approves New Park</h1>
  <p>After months of debate, the council voted 7-2 in favor…</p>

  <blockquote>
    <p>
      This park will be a gathering place for generations to come.
      It represents our commitment to green space in every neighborhood.
    </p>
    <cite>— Mayor Smith, in a press release</cite>
  </blockquote>

  <p>Construction is scheduled to begin in the spring…</p>
</article>

Multi-paragraph quote

<blockquote cite="https://example.com/speech">
  <p>We hold these truths to be self-evident, that all men are created equal…</p>
  <p>…that they are endowed by their Creator with certain unalienable Rights…</p>
  <p>…that among these are Life, Liberty and the pursuit of Happiness.</p>
  <footer>
    — <cite>The Declaration of Independence</cite>, 1776.
  </footer>
</blockquote>

10 Common Mistakes

MistakeWhy It HurtsFix
Putting text directly inside <blockquote> Loses paragraph semantics; some browsers render oddly Wrap text in <p> inside
Using cite attribute for author name Spec says URL only; not visible to user Use <cite> element visibly inside
<cite> for author instead of work title Invalid HTML5; <cite> is for work titles Use <span> or <b> for author name
Using <blockquote> for indentation Misleads screen readers; wrong semantics Use <div> with CSS margin-left
Forgetting cite attribute on external quotes Loses machine-readable source Add cite="URL"
Using <blockquote> for inline short quotes Block-level breaks paragraph flow Use <q> for inline quotes
Pull-quotes that duplicate text without aria-hidden Screen reader reads same text twice Add aria-hidden="true" or use role="presentation"

11 Try It Yourself

Exercise 1 — Cite a book Find a memorable passage from a favorite book. Wrap it in <blockquote> with:
  • The actual quote wrapped in <p>
  • A cite attribute with the book's URL (or a placeholder)
  • A <cite> element inside the blockquote with the book title
  • A footer with the author and year
Exercise 2 — Build a testimonial card Use a <figure> with <blockquote> and <figcaption> to build a customer testimonial. Style it as a card with a colored border, italic text, and a centered author name in the caption.
Exercise 3 — Pull-quote design Write a 4-paragraph article. Insert a pull-quote between paragraphs 2 and 3 that repeats a sentence from the article. Add the aria-hidden="true" attribute so screen readers do not announce the duplicate.
Exercise 4 — Nested quotes Write a paragraph that contains an inline quote (<q>) which itself contains another inline quote. Verify that the browser alternates between double and single quote characters correctly.

12 Summary

  • <blockquote> = block-level quotation from another source (or from the same article for pull-quotes).
  • Always wrap quote text in <p> inside <blockquote>.
  • The cite attribute holds a URL pointing to the source — invisible by default.
  • Use the <cite> element visibly inside (often inside a <footer>) for the source title.
  • Style with border-left, background, italic, or large pull-quote CSS.
  • For pull-quotes that duplicate article text, add aria-hidden="true".
  • Never use <blockquote> just for visual indentation.
