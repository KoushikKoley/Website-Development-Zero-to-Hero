Section 2.3 · Quotations & Citations

The <q> Element

The inline quotation — short quotes that live inside a paragraph. <q> adds the correct quotation marks automatically, switches them per language, and even alternates double and single quotes when nested. The smartest tiny element in HTML.

1 What Is the q Element?

The <q> element represents a short inline quotation that does not require a paragraph break. It is the inline counterpart to <blockquote>. Browsers automatically wrap the content in the appropriate quotation marks for the current language.

<p>
  As Einstein said, <q>Imagination is more important than knowledge.</q>
</p>

As Einstein said, Imagination is more important than knowledge.

Pro Tip The killer feature of <q> is automatic, language-aware quotation marks. Type the text once, and the browser inserts the right characters — double quotes in English, guillemets in French, low-high quotes in German — based on the lang attribute.

2 Basic Syntax

The <q> element is phrasing content — it lives inside paragraphs, headings, list items, and other inline containers. It accepts all global attributes, including lang, dir, class, and cite.

<p>
  The report states <q>progress has been significant</q>
  but cautions that <q>more work is needed</q>.
</p>

The report states progress has been significant but cautions that more work is needed.

Default rendering

Browsers wrap <q> content in double quotation marks ("…") using the CSS pseudo-elements ::before and ::after with the open-quote and close-quote content values. You can override these in CSS.

3 Automatic Quote Marks

The browser's default stylesheet essentially does this for <q>:

q::before { content: open-quote; }
q::after  { content: close-quote; }

The open-quote and close-quote keywords are CSS shorthand that pick the correct quotation characters based on the language. You can also set them explicitly with the quotes property:

q {
  quotes: "&#8220;" "&#8221;"    /* " " */
          "&#8216;" "&#8217;";   /* ' ' */
}

The first pair is for outer quotes; the second pair is for nested quotes. More pairs can be added for deeper nesting.

Info If you set quotes: none; or content: none; on q::before and q::after, the browser will not insert any quotation marks. The element still carries the semantic meaning of a quote.

4 Nested q Elements

When you nest <q> elements, the browser automatically alternates between outer and inner quote characters (typically double → single → double).

<p>
  She said, <q>He told me, <q>I'll be there</q> yesterday</q>.
</p>

She said, He told me, I'll be there yesterday.

Notice the alternation: outer quotes are double ("…"), inner quotes are single ('…'). This is exactly how a careful typesetter would format the same sentence.

Pro Tip Never add literal quotation marks inside <q> — the browser will add them automatically. Adding your own results in doubled-up quote characters: <q>"Hello"</q> renders as "Hello" (quotes inside quotes).

5 The cite Attribute

Like <blockquote>, the <q> element accepts a cite attribute holding a URL to the source. It is invisible by default but useful for tools and machine consumption.

<p>
  According to the
  <q cite="https://www.w3.org/TR/html/">
    HTML Living Standard
  </q>,
  the q element represents a quotation.
</p>
Common Mistake The cite attribute on <q> is not visible to users. If you want the source to be clickable, wrap the quote in an <a href="URL"> element or add a visible <cite> element nearby.

7 q vs Literal Quote Characters

You could just type "…" directly in your HTML. So why use <q>?

Use literal quotes when…

The text is not actually a quotation (e.g. "scare quotes", irony, or emphasis). Or when you need full control over the exact characters (e.g. typography-strict publication).

Use <q> when…

The text is genuinely a quotation from another source. The semantic value helps search engines, translation tools, and screen readers understand what is being quoted.

ApproachProsCons
Literal "…"Full control; works without CSSManual language switching; no semantics
<q> elementAutomatic language-aware marks; semantic; alternates on nestingRequires CSS support (universal today); slightly more verbose
HTML entities (&quot;, &ldquo;)Precise charactersSame as literal — no semantics, no auto-nesting
Pro Tip For multilingual sites or sites with quotes from multiple languages, <q> with per-element lang is the only way to get correct typography automatically. This is invaluable in academic, news, and legal publishing.

8 Styling q

Most of the time, leave the default browser behavior alone — the auto-quotes are already correct. But you can customize:

Custom quote characters

q {
  quotes: "&#8220;" "&#8221;"     /* outer: " " */
          "&#8216;" "&#8217;";    /* inner: ' ' */
}

/* Or use guillemets site-wide */
:lang(fr) q,
q:lang(fr) {
  quotes: "« " " »" "&#8249;" "&#8250;";
}

Remove the auto-quotes

q.no-quotes::before,
q.no-quotes::after {
  content: none;
}

Add a citation link style

q[cite] {
  background: #fef9c3;
  border-bottom: 1px dashed #ca8a04;
  cursor: help;
}

Style with a quote glyph on hover

q:hover::before { content: "\201C"; color: var(--brand); }
q:hover::after  { content: "\201D"; color: var(--brand); }

9 Real-World Examples

Inline quote with attribution

<p>
  <q cite="https://example.com/speech">Ask not what your country
  can do for you</q>, said President Kennedy in his inaugural address.
</p>

Multilingual article

<p>
  The French phrase <q lang="fr">joie de vivre</q>
  translates roughly to "joy of living".
</p>
<p>
  In German, one might say <q lang="de">Lebensfreude</q>,
  and in Spanish, <q lang="es">alegría de vivir</q>.
</p>

Nested quote inside a paragraph

<p>
  The witness testified: <q>I heard him say,
  <q>Don't tell anyone</q> before he left.</q>
</p>

Quote inside a heading

<h2>
  On the phrase <q>the customer is always right</q>
</h2>

Quote in a list item

<ul>
  <li>Favorite quote: <q>Less is more.</q></li>
  <li>Another: <q>Form follows function.</q></li>
</ul>

10 Accessibility

  • Screen readers typically announce the quotation marks when they encounter <q> — for example, NVDA may say "quote" before reading the content.
  • Some screen readers suppress the announcement if the quote is very short or if the surrounding context makes it clear.
  • The cite attribute (URL) is generally not announced.
Pro Tip For long quotes (3+ lines, multiple paragraphs), switch to <blockquote>. Screen-reader users navigate blockquotes differently, and the visual layout will be more appropriate.

11 Common Mistakes

MistakeWhy It HurtsFix
Adding literal "…" inside <q> Doubles the quote characters Let the browser add them automatically
Forgetting lang on foreign quotes Wrong quotation marks for the language Add lang="xx" to the <q> or ancestor
Using <q> for multi-paragraph quotes Inline element; block layout is wrong Use <blockquote>
Using <q> for non-quotation emphasis Wrong semantics; screen readers say "quote" Use <em> for emphasis or <i> for alternate voice
Putting cite attribute as plain text Must be a URL; invisible to users Use the <cite> element for visible attribution
Setting display: none on q::before only Asymmetric quotes (only closing remains) Use content: none on both ::before and ::after

12 Try It Yourself

Exercise 1 — Basic inline quotes Write a paragraph that contains two short inline quotes using <q>. Verify that the browser wraps them in double quotation marks automatically.
Exercise 2 — Nested quotes Write a sentence that contains a quote within a quote using nested <q> elements. Verify that the outer quotes are double and the inner are single.
Exercise 3 — Multilingual quotes Build a paragraph that quotes phrases in three different languages (English, French, German). Add the correct lang attribute to each <q>. Verify that each renders with the correct quotation marks for its language.
Exercise 4 — Custom quote characters Use the CSS quotes property to change the quotation marks used by <q> on your page. Try guillemets (« ») for outer quotes and corner brackets (「 」) for inner quotes. Verify nested quotes use the right pair.
Exercise 5 — q vs blockquote Write the same quotation as both an inline <q> inside a paragraph and as a standalone <blockquote>. Note the visual and semantic differences.

13 Summary

  • <q> = short inline quotation; browser adds quotation marks automatically.
  • Quotes are language-aware: set lang on <q> or an ancestor.
  • Nested <q> alternates between outer and inner quote characters.
  • The cite attribute holds a URL to the source (invisible by default).
  • Customize characters with the CSS quotes property.
  • For long or multi-paragraph quotes, use <blockquote>.
  • Never add literal quotation marks inside <q> — the browser adds them.
