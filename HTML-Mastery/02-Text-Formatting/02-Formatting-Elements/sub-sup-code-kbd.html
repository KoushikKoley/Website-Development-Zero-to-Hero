Section 2.2 · Formatting Elements

Sub · Sup · Code · Pre · Kbd · Samp · Var

2 <sub> — Subscript

The <sub> element renders text below the baseline at a smaller size. Its semantic meaning: this text is a subscript — a typographic convention with specific meaning in chemistry, mathematics, and footnotes.

Chemistry examples

<p>Water has the formula H<sub>2</sub>O.</p>
<p>Carbon dioxide: CO<sub>2</sub>. Methane: CH<sub>4</sub>.</p>
<p>Sulfuric acid: H<sub>2</sub>SO<sub>4</sub>.</p>

Water has the formula H2O.

Carbon dioxide: CO2. Methane: CH4.

Sulfuric acid: H2SO4.

Footnote references

<p>The study found surprising results.<sub>1</sub></p>
<p>...</p>
<p><sub>1</sub> Smith et al., 2023.</p>

Mathematical sequences

<p>The first term is a<sub>0</sub>, the nth term is a<sub>n</sub>.</p>

3 <sup> — Superscript

The <sup> element renders text above the baseline at a smaller size. It is used for exponents, ordinals, footnote markers, and trademarks.

Math examples

<p>Einstein's famous equation: E = mc<sup>2</sup>.</p>
<p>Pythagoras: a<sup>2</sup> + b<sup>2</sup> = c<sup>2</sup>.</p>
<p>2<sup>10</sup> = 1024.</p>
<p>Area of a circle: A = πr<sup>2</sup>.</p>

Einstein's famous equation: E = mc2.

Pythagoras: a2 + b2 = c2.

210 = 1024.

Area of a circle: A = πr2.

Ordinals

<p>She finished in 1<sup>st</sup> place.</p>
<p>The 3<sup>rd</sup> edition is now available.</p>
<p>On the 21<sup>st</sup> of May.</p>

She finished in 1st place.

The 3rd edition is now available.

Footnote markers

<p>The earth is round<sup>1</sup> and orbits the sun<sup>2</sup>.</p>
Pro Tip Avoid using <sup> for trademark symbols (™, ®) — use the actual Unicode characters &trade; and &reg; instead. They render at the correct size automatically.

4 <code> — Inline Code

The <code> element represents a fragment of computer code. Browsers render it in a monospace font by default. Use it for inline mentions of variables, function names, file paths, HTML tags, and short code snippets.

<p>Use the <code>Array.map()</code> method to transform each element.</p>
<p>The file is located at <code>/etc/nginx/nginx.conf</code>.</p>
<p>Set <code>font-size</code> in rem units.</p>
<p>The <code>&lt;article&gt;</code> element represents a self-contained composition.</p>

Use the Array.map() method to transform each element.

The file is located at /etc/nginx/nginx.conf.

Set font-size in rem units.

The <article> element represents a self-contained composition.

Common Mistake When showing HTML tags inside <code>, you must escape < and > as &lt; and &gt;. Otherwise, the browser will treat them as real tags and they will not display.

5 <pre> — Preformatted Text

The <pre> element represents preformatted text: whitespace, line breaks, and tabs are preserved exactly as written in the source. Browsers render it in monospace font with no automatic wrapping.

<pre>function greet(name) {
  return "Hello, " + name;
}

greet("World");
// → Hello, World</pre>

Use cases

  • Multi-line code blocks
  • ASCII art
  • Terminal output / log files
  • Email signatures with aligned text
  • Pre-formatted tables of data

ASCII art example

<pre>
       __
      /  \
     |    |
     |    |
    /      \
   /        \
  /__________\
</pre>
Info Inside <pre>, you still need to escape < and > as entities. The whitespace preservation only affects spaces, tabs, and newlines — angle brackets will still be parsed as tags.

6 <kbd> — Keyboard Input

The <kbd> element represents user input from a keyboard, voice input, or any other input device. Use it to mark up keystrokes, keyboard shortcuts, and menu paths in user instructions.

<p>To save, press <kbd>Ctrl</kbd> + <kbd>S</kbd>.</p>
<p>Press <kbd>Enter</kbd> to submit the form.</p>
<p>Use <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> on macOS.</p>
<p>Select <kbd>File</kbd> → <kbd>New</kbd> from the menu.</p>

To save, press Ctrl + S.

Press Enter to submit the form.

Use Cmd + Shift + P on macOS.

Select File → New from the menu.

Styling kbd to look like a keycap

kbd {
  display: inline-block;
  padding: 2px 8px;
  border: 1px solid #cbd5e1;
  border-bottom-width: 2px;
  border-radius: 6px;
  background: linear-gradient(180deg, #fff, #f1f5f9);
  font-family: ui-monospace, monospace;
  font-size: 0.85em;
  color: #0f172a;
  box-shadow: 0 1px 0 rgba(0,0,0,0.05);
}
Pro Tip Nested <kbd> inside <kbd> represents a single key that is itself a combination: <kbd><kbd>Ctrl</kbd>+<kbd>S</kbd></kbd> means "the Ctrl+S keystroke as a single unit". This is subtle but useful for advanced tutorials.

7 <samp> — Sample Output

The <samp> element represents sample output from a program or computer system. Use it to show what a program prints, what an error message looks like, or what a terminal returns.

<p>After running the command, you'll see:</p>
<p>
  <samp>Error: file not found at /var/log/app.log</samp>
</p>

<p>The server responds with:</p>
<p><samp>HTTP/1.1 200 OK
Content-Type: application/json
{"status": "success"}</samp></p>

After running the command, you'll see:

Error: file not found at /var/log/app.log

Combining <samp> with <kbd>

A common pattern: show the user input (<kbd>) followed by the resulting output (<samp>).

<p>
  <kbd>ping example.com</kbd>
  <samp>PING example.com (93.184.216.34): 56 data bytes
64 bytes from 93.184.216.34: icmp_seq=0 ttl=56 time=12.3 ms</samp>
</p>

8 <var> — Variable

The <var> element represents a variable in a mathematical expression or programming context. It can be a placeholder name the user is expected to replace, or an actual variable in code. Renders in italic by default.

<p>The area of a rectangle is <var>width</var> × <var>height</var>.</p>
<p>In the function <code>f(<var>x</var>) = <var>x</var><sup>2</sup></code>,
   <var>x</var> is the input.</p>
<p>To install, run: <code>npm install <var>package-name</var></code></p>

The area of a rectangle is width × height.

In the function f(x) = x2, x is the input.

To install, run: npm install package-name

Pro Tip <var> inside <code> clearly separates the actual code from the placeholder the reader should replace. This is much clearer than italicizing inside <code> alone.

9 Combining pre + code

For multi-line code blocks, the canonical pattern is to nest <code> inside <pre>. This gives you both whitespace preservation and the semantic "this is code" signal.

<pre><code>function fibonacci(n) {
  if (n <= 1) return n;
  return fibonacci(n - 1) + fibonacci(n - 2);
}
</code></pre>

Adding a language class for syntax highlighting

Many syntax highlighters (Prism, highlight.js, CodeMirror) look for a language-* class on the <code> element:

<pre><code class="language-javascript">
const greet = (name) => `Hello, ${name}!`;
</code></pre>

Recommended base CSS

pre {
  background: #1e1e2e;
  color: #cdd6f4;
  padding: 16px;
  border-radius: 8px;
  overflow-x: auto;
  font-family: ui-monospace, monospace;
  font-size: 0.9rem;
  line-height: 1.6;
}

pre code {
  background: transparent;
  color: inherit;
  padding: 0;
  font-size: inherit;
}

/* Inline code */
code {
  background: #eef2ff;
  color: #1e3a8a;
  padding: 2px 6px;
  border-radius: 4px;
  font-size: 0.9em;
}

11 Common Mistakes

MistakeWhy It HurtsFix
Using <sup> for "1st", "2nd" Visually OK but missing semantic context Use <sup> — it's actually the correct choice for ordinals
Forgetting to escape < in <code> Tags get parsed instead of displayed Use &lt; and &gt;
Using <pre> without <code> inside Loses the "this is code" semantic signal Nest <code> inside <pre>
Using <code> for non-code text just for monospace Misleads tools and search engines Use a <span class="mono"> instead
Using <kbd> for button text Buttons aren't keyboard input Use <button> or styled <span>
Long lines in <pre> causing horizontal scroll Poor mobile UX Use overflow-x: auto or white-space: pre-wrap
Using Unicode subscript characters instead of <sub> Inconsistent rendering; not semantic Use <sub> for proper subscripts

13 Summary

  • <sub> = subscript for chemistry (H₂O) and footnote refs.
  • <sup> = superscript for exponents (x²), ordinals (1st), footnote markers.
  • <code> = inline code, monospace by default.
  • <pre> = block that preserves whitespace; pair with <code> for code blocks.
  • <kbd> = keyboard keys and shortcuts.
  • <samp> = sample program output.
  • <var> = variables and placeholders in math/code.
  • Always escape < and > as entities inside <code> and <pre>.
