Section 2.2 · Formatting Elements

<abbr> · <cite> · <dfn> · <address>

Four elements that mark up the meta-information of prose: abbreviations and their expansions, citations of creative works, the defining instance of a term, and contact information. Each one tells machines and readers "this isn't just text — it carries a specific role."

2 <abbr> — Abbreviation

The <abbr> element represents an abbreviation or acronym. Providing a title attribute with the full expansion allows browsers and assistive tech to show the full form on hover or to announce it.

<p>
  The <abbr title="World Wide Web Consortium">W3C</abbr>
  is the main international standards organization for the World Wide Web.
</p>

The W3C is the main international standards organization for the World Wide Web.

Hover over "W3C" to see the tooltip.

Acronyms vs initialisms

Technically, an acronym is pronounced as a word (NASA, NATO, laser), while an initialism is pronounced letter by letter (FBI, HTML, CPU). The HTML spec uses <abbr> for both. The obsolete <acronym> element was removed in HTML5.

<!-- Acronyms (pronounced as words) -->
<abbr title="National Aeronautics and Space Administration">NASA</abbr>
<abbr title="Light Amplification by Stimulated Emission of Radiation">laser</abbr>

<!-- Initialisms (pronounced letter by letter) -->
<abbr title="Federal Bureau of Investigation">FBI</abbr>
<abbr title="HyperText Markup Language">HTML</abbr>

3 The title Attribute

The title attribute provides the full expansion of the abbreviation. Browsers display it as a tooltip on hover, and screen readers may announce it instead of (or in addition to) the abbreviated form.

<p>
  The meeting starts at <abbr title="Post Meridiem (afternoon)">PM</abbr>
  or <abbr title="Ante Meridiem (morning)">AM</abbr>.
</p>
Pro Tip Define an abbreviation only on its first occurrence in a document. Repeating the title on every instance clutters the markup. After the first definition, subsequent uses can be plain text.

Styling abbr

Many sites add a subtle dotted underline to indicate the abbreviation is hoverable:

abbr[title] {
  cursor: help;
  text-decoration: underline dotted;
  text-underline-offset: 2px;
}

/* Optional: only style abbrs that actually have a title */
abbr[title]:hover::after {
  content: " (" attr(title) ")";
  font-size: 0.85em;
  color: var(--ink-soft);
}

4 Abbreviation Patterns

First-occurrence pattern

<p>
  <abbr title="Application Programming Interface">API</abbr>
  design is hard. A good API lets developers build quickly.
  The best APIs feel invisible.
</p>
<!-- Subsequent uses are plain "API" -->

Inline expansion

For very important terms, expand the abbreviation in prose on first use:

<p>
  We use a Content Delivery Network (CDN) to cache assets globally.
  The <abbr title="Content Delivery Network">CDN</abbr>
  reduces latency for users in distant regions.
</p>

5 <cite> — Citation

The <cite> element represents the title of a creative work: a book, a film, a song, an article, a painting, a TV show, a legal case, a video game, etc. It renders in italic by default.

<p>
  My favorite novel is <cite>Dune</cite> by Frank Herbert.
</p>

<p>
  In the film <cite>Blade Runner</cite>, the protagonist…
</p>

<p>
  As Smith notes in <cite>The Wealth of Nations</cite>,
  markets tend toward equilibrium.
</p>

My favorite novel is Dune by Frank Herbert.

In the film Blade Runner, the protagonist…

Common Mistake The HTML5 spec changed <cite> to mark only the title of the work, not the author or person. Wrapping a person's name in <cite> is invalid HTML5. Use a regular <span> or <b> for author names.

What counts as a "creative work"?

  • Books, novels, plays, poems
  • Movies, TV shows, web series
  • Songs, albums, symphonies
  • Articles, blog posts, news stories
  • Paintings, sculptures, photographs
  • Video games, board games
  • Legal cases (Brown v. Board of Education)
  • Software, websites, apps

6 <dfn> — Definition Term

The <dfn> element represents the defining instance of a term. The defining instance is the first time a term is introduced and defined in a document. Browsers render it in italic.

<p>
  A <dfn>webhook</dfn> is an HTTP callback that fires when
  an event occurs in a system.
</p>

A webhook is an HTTP callback that fires when an event occurs in a system.

Definition with explicit term

If the <dfn> contains a nested element like <abbr>, the innermost element is taken as the term being defined:

<p>
  <dfn><abbr title="HyperText Markup Language">HTML</abbr></dfn>
  is the standard markup language for documents on the web.
</p>

Definition with title attribute

If you add a title attribute to <dfn>, its value is the term being defined (useful when the term differs from the visible text):

<p>
  The <dfn title="API endpoint">URL pattern</dfn>
  defines where an API can be reached.
</p>

7 Linked Definitions

The canonical pattern: give your <dfn> an id, then any later reference to that term links back to it with <a href="#fragment">. This is exactly how glossaries, Wikipedia, and technical docs work.

<p>
  A <dfn id="def-webhook">webhook</dfn> is an HTTP callback
  that fires when an event occurs.
</p>

<p>
  To configure a <a href="#def-webhook">webhook</a>,
  visit the Settings → Integrations page.
</p>
Pro Tip This pattern — defining a term once with <dfn>, then linking subsequent mentions to it — is the most powerful yet underused feature of <dfn>. It creates a built-in glossary system with no JavaScript.

8 <address> — Contact Information

The <address> element represents contact information for a person, people, or organization. It is intended for the author or owner of the current document (or article, if scoped to an <article>).

<footer>
  <address>
    Written by <a href="mailto:ada@example.com">Ada Lovelace</a>.<br>
    Visit my blog at <a href="https://ada.example.com">ada.example.com</a>.<br>
    London, United Kingdom
  </address>
</footer>
Written by Ada Lovelace.
Visit my blog at ada.example.com.
London, United Kingdom

What <address> is for

  • Email addresses
  • Phone numbers
  • Physical / mailing addresses
  • Website URLs of the contact
  • Social media handles
  • Any combination of the above

What <address> is NOT for

  • Arbitrary postal addresses (use <p> with <br>)
  • Customer support addresses unrelated to the document author
  • Page footer copyright text
  • Map locations or directions
Common Mistake Despite the name, <address> is not a generic container for any postal address. It is specifically for contact information about the document or article author. For a customer's shipping address, use a regular paragraph.

Nested inside an article

<article>
  <h1>Why Static Sites Are Faster</h1>
  <p>...</p>
  <address>By Jane Doe, <a href="mailto:jane@example.com">jane@example.com</a></address>
</article>

When scoped inside an <article>, the <address> represents the contact info for the author of that article, not the entire page.

9 Real-World Examples

Glossary entry

<dl>
  <dt><dfn id="def-api">API</dfn></dt>
  <dd>
    <abbr title="Application Programming Interface">API</abbr>:
    a set of rules for building software applications.
  </dd>
</dl>

Article with citations

<article>
  <h1>The State of Web Performance</h1>
  <p>
    As noted in <cite>High Performance Web Sites</cite>
    by Steve Souders, 80% of page load time is spent on the front end.
  </p>
  <p>
    The <abbr title="World Wide Web Consortium">W3C</abbr>
    has published guidelines on this topic.
  </p>
</article>

Document footer with contact info

<footer>
  <address>
    <a href="/about">The Editorial Team</a><br>
    <a href="mailto:editor@example.com">editor@example.com</a><br>
    Phone: +1 (555) 123-4567
  </address>
</footer>

Math reference with linked terms

<p>
  A <dfn id="def-prime">prime number</dfn> is a natural number
  greater than 1 with exactly two divisors: 1 and itself.
</p>
<p>
  The largest known <a href="#def-prime">prime number</a>
  has over 24 million digits.
</p>

10 Accessibility

  • <abbr title="..."> — Screen readers may read the title instead of the abbreviation. NVDA users can configure this behavior. Always provide a title for clarity.
  • <cite> — Typically no special announcement, but the italic styling carries visual weight.
  • <dfn> — Some screen readers announce "definition" or "term".
  • <address> — Most screen readers announce "contact information for the author".
Pro Tip For crucial abbreviations (legal, medical, technical), expand the term in prose on first use, then use <abbr title="..."> for subsequent occurrences. This way both sighted and screen-reader users get the full picture.

11 Common Mistakes

MistakeWhy It HurtsFix
<cite> on an author name Invalid HTML5; author ≠ title of work Use <span> or <b>
Using <acronym> Removed in HTML5; obsolete Use <abbr> for both acronyms and initialisms
Repeating title on every abbreviation occurrence Clutters markup; tooltips everywhere Define once on first use; plain text after
<address> for arbitrary postal addresses Wrong semantics; misleading for assistive tech Use <p> with <br>
<dfn> on every mention of a term <dfn> is for the defining instance only Use plain text or link to the <dfn> for later mentions
Using <cite> for inline quotes Citation is the source title, not the quote text Use <q> or <blockquote>
Using title on <abbr> for non-abbreviation text Misleads screen readers and search engines Use <span title="..."> for general tooltips

12 Try It Yourself

Exercise 1 — Define abbreviations Take a paragraph from a technical article you have written. Mark up at least three abbreviations with <abbr title="...">. Verify the tooltips appear on hover.
Exercise 2 — Build a glossary Create a glossary section with three definitions using <dfn> (with id attributes). Then write a separate paragraph that uses each term in a sentence, linking each occurrence to its definition.
Exercise 3 — Cite your sources Write a one-paragraph book review. Wrap the book title in <cite>. Cite at least two other works (films, songs, articles) using <cite> as well.
Exercise 4 — Page footer Build a complete footer with an <address> element containing an author name, email link, website link, and physical location. Use <br> for line breaks within the address.

13 Summary

  • <abbr> = abbreviation or acronym; use title attribute for the full expansion.
  • Define an abbreviation only on its first occurrence in a document.
  • <cite> = title of a creative work (book, film, song, article). Never for author names.
  • <dfn> = the defining instance of a term. Add an id so later mentions can link back.
  • <address> = contact information for the document/article author. Not a generic postal address.
  • The obsolete <acronym> element was removed; use <abbr> for both acronyms and initialisms.
  • For multilingual abbreviations, add lang attributes for correct pronunciation.
