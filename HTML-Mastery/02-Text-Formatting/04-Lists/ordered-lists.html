Section 2.4 · Lists

Ordered Lists <ol> & <li>

When order matters — steps in a recipe, ranking, instructions, changelogs — reach for <ol>. The browser numbers items automatically, but with start, reversed, and type attributes you have full control. And CSS counters unlock entirely custom numbering schemes.

1 What Is an Ordered List?

An ordered list represents a collection of items where the order is meaningful — instructions, steps, rankings, or sequences. The browser renders each item with a number (or letter) by default.

<ol>
  <li>Preheat the oven to 350°F.</li>
  <li>Mix flour and sugar.</li>
  <li>Bake for 30 minutes.</li>
</ol>
  1. Preheat the oven to 350°F.
  2. Mix flour and sugar.
  3. Bake for 30 minutes.
Info If you re-arrange the items in an <ol>, the meaning changes — that is the semantic test for "ordered". For a list where order is arbitrary (shopping list, feature list), use <ul>.

2 Basic Syntax

Like <ul>, the only allowed direct children of <ol> are <li> elements. Each <li> can contain any flow content.

<ol>
  <li>Sign up for an account</li>
  <li>Verify your email address</li>
  <li>
    Complete your profile:
    <ul>
      <li>Add a profile photo</li>
      <li>Write a short bio</li>
    </ul>
  </li>
  <li>Start exploring!</li>
</ol>

3 The type Attribute

The type attribute changes the numbering style. Five values are supported:

ValueStyleExampleUse case
1 (default)Decimal numbers1, 2, 3Most common; steps, rankings
aLowercase lettersa, b, cOutline-style sub-items
AUppercase lettersA, B, CAppendices, formal outlines
iLowercase Romani, ii, iiiLegal documents, prefaces
IUppercase RomanI, II, IIIChapter numbers, formal
 
<ol type="1">
  <li>First item</li>
  <li>Second item</li>
</ol>

<ol type="A">
  <li>Appendix A</li>
  <li>Appendix B</li>
</ol>

<ol type="i">
  <li>Item one</li>
  <li>Item two</li>
</ol>
  1. Decimal
  2. Two
  1. Lowercase a
  2. Lowercase b
  1. Uppercase A
  2. Uppercase B
  1. Roman i
  2. Roman ii
  1. Roman I
  2. Roman II
Pro Tip Modern CSS also exposes list-style-type with the same values, plus many more (Japanese-formal, Georgian, Hebrew, etc.). The CSS approach is preferred for new code, but the type attribute still works and is more concise for simple cases.

4 The start Attribute

The start attribute sets the starting number for the list. It accepts an integer regardless of the type — the browser converts it appropriately.

<ol start="5">
  <li>Fifth step</li>
  <li>Sixth step</li>
  <li>Seventh step</li>
</ol>

<ol type="A" start="3">
  <li>Starts at C</li>
  <li>Then D</li>
</ol>
  1. Fifth step
  2. Sixth step
  3. Seventh step
  1. Starts at C
  2. Then D

The start attribute is useful for splitting a list across multiple sections of a document while keeping the numbering continuous.

5 The reversed Attribute

The reversed attribute is a boolean: when present, the list counts down instead of up. Useful for countdowns, "top N" rankings, and changelogs.

<ol reversed>
  <li>First place (gold)</li>
  <li>Second place (silver)</li>
  <li>Third place (bronze)</li>
</ol>
  1. First place (gold)
  2. Second place (silver)
  3. Third place (bronze)

Combine reversed with start to control the exact starting number:

<ol reversed start="10">
  <li>Item 10</li>
  <li>Item 9</li>
  <li>Item 8</li>
</ol>
Info reversed is a boolean attribute — its presence alone activates it. You do not need to write reversed="true"; just reversed is enough.

6 The value Attribute on <li>

Individual <li> elements can override their number with the value attribute. Subsequent items continue from that value.

<ol>
  <li>Item 1</li>
  <li>Item 2</li>
  <li value="5">Item 5 (jumped)</li>
  <li>Item 6 (continues)</li>
</ol>
  1. Item 1
  2. Item 2
  3. Item 5 (jumped)
  4. Item 6 (continues)

This is useful when you want to "skip" steps in a tutorial or restart numbering in a continued list.

7 Nested Ordered Lists

Nested <ol> elements create hierarchical numbering — perfect for outlines, legal documents, and technical specs.

<ol>
  <li>Introduction
    <ol type="a">
      <li>Background</li>
      <li>Motivation</li>
    </ol>
  </li>
  <li>Methodology
    <ol type="a">
      <li>Data collection</li>
      <li>Analysis approach</li>
    </ol>
  </li>
</ol>
  1. Introduction
    1. Background
    2. Motivation
  2. Methodology
    1. Data collection
    2. Analysis approach
Pro Tip Mixing type values for different levels (e.g. 1, a, i) creates a clean academic outline. Many style guides including APA and MLA recommend this pattern.

Pro Tip Ask yourself: "If I shuffle the items, does the meaning change?" If yes, use <ol>. If no, use <ul>.

9 CSS Counters

When the type and start attributes aren't enough, CSS counters let you build entirely custom numbering schemes — multi-level, with prefixes, suffixes, or special formatting.

Basic counter

ol.custom {
  list-style: none;
  counter-reset: step;
  padding-left: 0;
}
ol.custom li {
  counter-increment: step;
  padding: 12px 16px 12px 60px;
  position: relative;
  margin-bottom: 8px;
  background: linear-gradient(135deg, #eef2ff, #f0fdf4);
  border-radius: 8px;
}
ol.custom li::before {
  content: counter(step);
  position: absolute;
  left: 12px; top: 50%;
  transform: translateY(-50%);
  width: 32px; height: 32px;
  background: linear-gradient(135deg, #2563eb, #7c3aed);
  color: white;
  border-radius: 50%;
  display: flex; align-items: center; justify-content: center;
  font-weight: 700;
}
  1. Sign up for an account
  2. Verify your email address
  3. Complete your profile
  4. Start exploring!

Multi-level counters

ol.outline {
  list-style: none;
  counter-reset: section;
  padding-left: 0;
}
ol.outline > li {
  counter-increment: section;
  margin-bottom: 8px;
}
ol.outline > li::before {
  content: counter(section) ". ";
  font-weight: 700;
  color: var(--brand);
}
ol.outline ol {
  list-style: none;
  counter-reset: subsection;
  padding-left: 24px;
}
ol.outline ol > li {
  counter-increment: subsection;
}
ol.outline ol > li::before {
  content: counter(section) "." counter(subsection) " ";
  color: var(--brand-2);
}

This produces numbering like 1., 1.1, 1.2, 2., 2.1 — common in legal documents and technical specifications.

Custom prefix and suffix

ol.steps li::before {
  content: "Step " counter(step) ": ";
  font-weight: 600;
  color: var(--brand);
}

ol.chapters li::before {
  content: "Chapter " counter(chapter) " — ";
}
Info CSS counters are powerful but come with one caveat: screen readers may not announce custom counter content consistently. For accessibility-critical content, consider adding visible text labels too.

11 Accessibility

  • Screen readers announce <ol> as a list with N items, similar to <ul>.
  • Numbering is announced before each item ("1, item text").
  • When using CSS counters, the announcement may be inconsistent — consider adding visible text labels for accessibility-critical content.
  • If the order is purely visual (the items would still make sense shuffled), prefer <ul> to avoid implying false sequence.
Pro Tip For very long numbered lists (100+ items), add a "Skip to next section" link above the list. Screen-reader users will appreciate not having to navigate through all items.

12 Common Mistakes

MistakeWhy It HurtsFix
Using <ol> when order doesn't matter Implies a false sequence Use <ul>
Hard-coding numbers in <li> text Doesn't auto-renumber when items change Let the browser number them
Nesting <ol> directly inside <ol> Invalid HTML Wrap nested list in an <li>
Forgetting type on academic outlines Style guide requires specific numbering Use type="A", type="i", etc.
Using type on <li> Not supported — type only on <ol> Set on parent <ol>
Using CSS counters without visible text backup Screen readers may miss the numbering Add visible labels for critical content
Writing reversed="true" Boolean attribute; presence alone activates Just use reversed

13 Try It Yourself

Exercise 1 — Recipe Write a recipe with 6 numbered steps. After step 3, add an unordered sub-list of ingredients. Verify the numbering continues correctly.
Exercise 2 — Legal outline Build a legal-style outline using nested <ol type="I"> and <ol type="A"> for two levels. Add at least 2 top-level items and 2 sub-items each.
Exercise 3 — Top 5 countdown Build a "Top 5 movies of all time" list that counts down from 5 to 1. Use the reversed attribute. Verify it renders as 5, 4, 3, 2, 1.
Exercise 4 — CSS counter timeline Build a vertical timeline using CSS counters. Each step should display a circular numbered badge to the left, with content on the right. Add 4 steps with titles and descriptions.
Exercise 5 — Multi-level numbering Recreate a technical specification outline with numbering like "1.", "1.1", "1.2", "2.", "2.1", "2.2" using CSS counters. No JavaScript allowed.

14 Summary

  • <ol> = ordered list, items where order is meaningful.
  • The type attribute: 1 (default), a, A, i, I.
  • The start attribute sets the starting number.
  • The reversed attribute counts down (boolean).
  • The value attribute on individual <li> overrides the number.
  • Nested <ol> must be inside an <li>.
  • Use <ul> when order is arbitrary; <ol> when it's meaningful.
  • CSS counters enable fully custom numbering schemes — but verify screen-reader behavior.
