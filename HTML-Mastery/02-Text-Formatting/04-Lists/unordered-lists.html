Section 2.4 · Lists

Unordered Lists <ul> & <li>

The workhorse of web content: navigation menus, feature lists, checklists, breadcrumbs, tag clouds, and bullet points everywhere. Master <ul> and you will write cleaner, more accessible HTML for the rest of your career.

1 What Is an Unordered List?

An unordered list is a collection of items where the order does not matter — the items are related but not sequential. The browser renders each item with a bullet point by default (a small disc).

The element is one of the oldest in HTML, dating back to HTML 2.0 (1995). It is also one of the most abused — many developers don't realize just how flexible and semantic it is.

Info Use <ul> when items are members of a set without an inherent order (a shopping list, a list of features, a navigation menu). Use <ol> when the order matters (steps in a recipe, rankings, instructions).

2 Basic Syntax

<ul>
  <li>Apples</li>
  <li>Oranges</li>
  <li>Bananas</li>
</ul>
  • Apples
  • Oranges
  • Bananas

The only allowed direct children of <ul> are <li> elements. The closing </li> tag is technically optional but should always be written.

3 The <li> Element

The <li> (list item) element represents a single item in any list — ordered, unordered, or description. It can contain almost anything: text, images, links, headings, paragraphs, even other lists.

<ul>
  <li>A simple text item</li>
  <li>
    <h3>An item with a heading</h3>
    <p>And a paragraph of description.</p>
    <a href="/learn-more">Learn more</a>
  </li>
  <li>
    <img src="icon.png" alt="Feature icon">
    <strong>Feature name</strong>
  </li>
</ul>

The value attribute (rare on <ul>)

Although the value attribute on <li> only really makes sense for <ol>, it is technically allowed on any <li>. On <ul> it has no visible effect.

4 Nested Lists

You can place a <ul> (or <ol>) inside an <li> to create a nested list. The browser automatically indents nested lists and (by default) changes the bullet style for each level.

<ul>
  <li>Fruits
    <ul>
      <li>Apples</li>
      <li>Oranges</li>
    </ul>
  </li>
  <li>Vegetables
    <ul>
      <li>Carrots</li>
      <li>Spinach</li>
    </ul>
  </li>
</ul>
  • Fruits
    • Apples
    • Oranges
  • Vegetables
    • Carrots
    • Spinach
Common Mistake The nested list must go inside an <li>, not as a sibling of <li> elements. Putting <ul> directly inside another <ul> (skipping the <li> wrapper) is invalid HTML.

5 list-style-type CSS

The list-style-type CSS property changes the bullet character. This is the most common customization for unordered lists.

ValueBulletUse case
disc (default)•Standard bulleted list
circle○Softer visual weight
square■Strong, geometric
none(no bullet)Nav menus, custom bullets
"→"→Custom string
'\1F44d'👍Emoji or Unicode
 
ul.disc     { list-style-type: disc; }
ul.circle   { list-style-type: circle; }
ul.square   { list-style-type: square; }
ul.none     { list-style-type: none; }
ul.arrow    { list-style-type: "→ "; }
ul.emoji    { list-style-type: "👍 "; }

  • square

6 Custom Bullets with Images

For full control, use the list-style-image property or the more flexible ::marker pseudo-element.

list-style-image (simple)

ul.checkmarks {
  list-style-image: url("check.svg");
  list-style-position: outside;
}

The ::marker pseudo-element (modern)

ul.fancy li::marker {
  content: "✦ ";
  color: var(--brand);
  font-size: 1.1em;
}

/* Different marker per item */
ul.priority li:nth-child(1)::marker { content: "🔴 "; }
ul.priority li:nth-child(2)::marker { content: "🟡 "; }
ul.priority li:nth-child(3)::marker { content: "🟢 "; }

Background-image technique (most flexible)

ul.icon-bullets {
  list-style: none;
  padding-left: 0;
}
ul.icon-bullets li {
  padding-left: 28px;
  background-image: url("check.svg");
  background-repeat: no-repeat;
  background-position: 0 50%;
  background-size: 18px;
  margin-bottom: 8px;
}
Pro Tip The ::marker pseudo-element is the modern way to style bullets. It supports content, color, font-size, and a few text properties. Browser support is now universal in modern browsers (Chrome 86+, Firefox 68+, Safari 11.1+).

7 Removing Bullets

The single most common list customization is to remove the bullets entirely — for navigation menus, tag clouds, and feature grids. This is the standard "list reset":

ul.reset {
  list-style: none;     /* remove bullets */
  margin: 0;            /* remove default margin */
  padding: 0;           /* remove default padding */
}

The shorthand list-style: none clears list-style-type, list-style-image, and list-style-position in one go.

8 Navigation Menus

Navigation menus are one of the most important uses of <ul>. Each menu item is a list item containing a link. This pattern is accessible, semantic, and flexible.

<nav aria-label="Main navigation">
  <ul>
    <li><a href="/" aria-current="page">Home</a></li>
    <li><a href="/products">Products</a></li>
    <li><a href="/about">About</a></li>
    <li><a href="/contact">Contact</a></li>
  </ul>
</nav>
  • Home
  • Products
  • About
  • Contact
nav ul {
  list-style: none;
  margin: 0; padding: 0;
  display: flex; gap: 4px;
  background: #0f172a;
  padding: 8px;
  border-radius: 8px;
}

nav a {
  color: #f8fafc;
  text-decoration: none;
  padding: 8px 16px;
  border-radius: 4px;
  display: block;
}

nav a:hover { background: rgba(255,255,255,0.1); }
nav a[aria-current="page"] {
  background: var(--brand);
}
Pro Tip Always wrap nav menus in a <nav> element with an aria-label like "Main navigation". Use aria-current="page" on the active link. Screen readers announce the menu as a navigation region and the current page is clearly identified.

10 Accessibility

  • Screen readers announce <ul> as a list with N items. NVDA users hear "list with 3 items" before the items are read.
  • If you set list-style: none, the browser still exposes the list semantics to assistive tech — but only if you keep the <ul> / <li> structure.
  • Setting role="presentation" or aria-hidden="true" on a list will hide it from screen readers — use with care.
  • Always wrap nav menus in <nav aria-label="..."> so screen readers can identify the navigation region.
  • For breadcrumbs, use <nav aria-label="Breadcrumb"> and mark the current page with aria-current="page".
Common Mistake Don't replace lists with <div> elements "for easier styling". Screen readers won't announce them as lists, losing the item count and navigation shortcuts. Use real <ul> / <li> and override styles with CSS.

11 Common Mistakes

MistakeWhy It HurtsFix
Nesting <ul> directly inside <ul> Invalid HTML; breaks list structure Wrap nested list inside an <li>
Putting non-<li> children in <ul> Invalid HTML; parser may close <ul> early Only <li> can be a direct child
Omitting closing </li> tags Valid but confusing; hard to maintain Always close <li> tags
Using <div> instead of <ul> for nav menus Loses list semantics; screen readers can't navigate Use real <ul>/<li> structure
Wrapping multiple items in one <li> Breaks screen-reader item counting One <li> per item
Skipping <nav aria-label> on nav menus Multiple nav regions are indistinguishable Add aria-label="Main nav" etc.
Forgetting to set list-style: none when needed Default bullets appear in nav menus Always reset when using ul for non-bulleted UI
Using list-style-type to convey meaning Color/symbol changes don't reach screen readers Use text labels or ARIA attributes too

12 Try It Yourself

Exercise 1 — Build a feature list Create a "Why choose us?" section with 4-5 features, each using emoji bullets. Use the ::marker pseudo-element to color the bullets.
Exercise 2 — Two-level nested list Create a category/subcategory list for an e-commerce site. Top-level: Electronics, Clothing, Books. Each should have 2-3 sub-items. Verify the indentation increases for the nested level.
Exercise 3 — Horizontal nav menu Build a navigation bar with 5 menu items. Use list-style: none and display: flex to lay items out horizontally. Style the active item with aria-current="page".
Exercise 4 — Checklist with custom bullets Build a todo checklist with check marks (✓) as bullets. Use CSS classes .done and .todo to style completed vs. pending items differently. Add a strike-through on completed items.
Exercise 5 — Custom image bullets Find or create a small SVG icon (e.g. a star, check, or arrow). Use list-style-image to apply it as the bullet for a list. Then do the same with the background-image technique. Compare browser rendering.

13 Summary

  • <ul> = unordered list; <li> = list item.
  • Only <li> elements can be direct children of <ul>.
  • Nested lists must go inside an <li>, never directly inside the parent <ul>.
  • Customize bullets with list-style-type, list-style-image, or ::marker.
  • Always reset bullets (list-style: none; margin: 0; padding: 0;) for nav menus.
  • Wrap nav menus in <nav aria-label="..."> and use aria-current="page" for the active item.
  • Real <ul>/<li> structure preserves screen-reader list semantics — don't replace with <div>.
