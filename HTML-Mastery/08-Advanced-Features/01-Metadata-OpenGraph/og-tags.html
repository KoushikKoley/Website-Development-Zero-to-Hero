Open Graph Protocol

When you paste a link into Facebook, LinkedIn, Slack, Discord, iMessage, or Telegram, the platform scrapes the URL and renders a rich "preview card" — image, title, description, site name. That data comes from Open Graph meta tags. Originally Facebook's invention, OG has become the de facto standard for social-media link previews across the web.

1 What is Open Graph?

Open Graph (OG) is a metadata protocol introduced by Facebook in 2010. It lets any web page become a "rich object" in social graphs — meaning when someone shares the URL, the platform displays a card with title, description, and image instead of just a bare link.

The protocol lives entirely in <meta> tags inside the <head>, using property (not name) attributes prefixed with og::

<head>
  <meta property="og:title" content="The Hitchhiker's Guide to HTML">
  <meta property="og:description" content="A complete tutorial covering everything from DOCTYPE to Web Components.">
  <meta property="og:image" content="https://example.com/images/og-cover.jpg">
  <meta property="og:url" content="https://example.com/html-guide">
  <meta property="og:type" content="article">
</head>

The original spec at ogp.me is just a few pages and well worth a read.

property vs name OG tags use property="og:...", not name="og:...". The property attribute was RDFa's invention; OG borrowed it for its extensibility (so og:image:url and og:image:width work as structured sub-properties). All major crawlers correctly read both, but the spec uses property.

2 The Four Required Tags

The OG spec calls these "the four required properties" — every page using OG should set them all.

TagPurposeExample
og:titleThe title of the page as it should appear in the preview card. Without any branding or site name — that's separate.The Hitchhiker's Guide to HTML
og:typeThe type of object. website is the catchall. article for news/blog posts, profile for people, book, video.movie, etc.article
og:imageURL to the image used in the preview. Should be at least 1200×630px, JPG or PNG, under 8 MB.https://example.com/og/cover.jpg
og:urlThe canonical URL of the page. Always set this even if it equals the current URL, so previews are consistent across share paths.https://example.com/post/123
Common Mistake Forgetting og:url. If your page is reachable via multiple URLs (e.g., example.com/post and www.example.com/post), platforms may treat them as separate share objects, splitting your engagement metrics. og:url makes the canonical URL explicit.

3 og:type — Beyond "website"

The og:type tag tells the platform what kind of object the page represents. website is the default, but specifying a more precise type enables type-specific properties.

TypeUse forType-specific properties
websiteHomepages, landing pages, generic pages—
articleNews stories, blog postsarticle:published_time, article:author, article:section, article:tag
productE-commerce product pagesproduct:price:amount, product:price:currency, product:availability
profileUser profile pagesprofile:first_name, profile:last_name, profile:username, profile:gender
bookBook detail pagesbook:author, book:isbn, book:release_date
video.movie, video.episode, video.tv_show, video.otherVideo contentvideo:duration, video:release_date, video:tag
music.song, music.albumMusic contentmusic:duration, music:musician

Article example

<meta property="og:type" content="article">
<meta property="og:title" content="How browsers render CSS">
<meta property="og:url" content="https://example.com/posts/css-render">
<meta property="og:image" content="https://example.com/og/css-render.jpg">
<meta property="article:published_time" content="2024-03-15T08:00:00Z">
<meta property="article:modified_time" content="2024-03-16T10:30:00Z">
<meta property="article:author" content="https://example.com/authors/jane">
<meta property="article:section" content="Browsers">
<meta property="article:tag" content="CSS">
<meta property="article:tag" content="performance">

Product example

<meta property="og:type" content="product">
<meta property="og:title" content="Acme Wireless Headphones">
<meta property="og:image" content="https://shop.example.com/og/headphones.jpg">
<meta property="product:price:amount" content="199.00">
<meta property="product:price:currency" content="USD">
<meta property="product:availability" content="oos">
<!-- availability values: "in stock", "oos" (out of stock), "pending" -->
Pro Tip For products, also add JSON-LD schema.org Product markup. The two systems complement each other: OG powers social-media previews; schema.org powers Google rich results.

4 Optional Tags

TagPurpose
og:site_nameThe name of the overall site (not the page). e.g. "The New York Times" — different from og:title which is the article title.
og:descriptionA one- or two-sentence description. Typically shown below the title in preview cards.
og:localeThe page's locale, e.g. en_US or fr_FR. Defaults to en_US.
og:locale:alternateOther locales this page is available in. Repeat for each.
og:determinerThe word that should precede the title in a sentence: "a", "an", "the", "auto", "". Almost never used in practice.
 
<meta property="og:site_name" content="The Daily Probe">
<meta property="og:description" content="A complete tutorial covering everything from DOCTYPE to Web Components.">
<meta property="og:locale" content="en_US">
<meta property="og:locale:alternate" content="fr_FR">
<meta property="og:locale:alternate" content="es_ES">
<meta property="og:locale:alternate" content="ja_JP">

5 og:image Deep Dive

The image is the most impactful OG tag — it's what catches the eye in a feed full of links. Get it right.

Recommended dimensions

Use caseRecommendedMinimum
Standard OG image (1.91:1 ratio)1200 × 630 px600 × 315 px
Square OG image (1:1 ratio, for small previews)1080 × 1080 px200 × 200 px
Large OG image (for summary_large_image Twitter Card)1200 × 628 pxsame as standard

Structured image properties

For best results, declare the image's dimensions and MIME type so platforms don't have to fetch the image to know its size:

<meta property="og:image" content="https://example.com/og/cover.jpg">
<meta property="og:image:secure_url" content="https://example.com/og/cover.jpg">
<meta property="og:image:type" content="image/jpeg">
<meta property="og:image:width" content="1200">
<meta property="og:image:height" content="630">
<meta property="og:image:alt" content="Stylized book cover showing a planet with the title overlay">

Multiple images

You can declare multiple og:image tags. Some platforms (notably Facebook) let the user pick from them; others just use the first.

<meta property="og:image" content="https://example.com/og/cover.jpg">
<meta property="og:image" content="https://example.com/og/cover-square.jpg">
<meta property="og:image" content="https://example.com/og/author-photo.jpg">
Common Mistakes
  • Using a relative URL like /images/cover.jpg — most platforms require absolute URLs.
  • Using HTTP for og:image when the page is HTTPS — many platforms refuse to embed mixed-content images. Use og:image:secure_url with HTTPS.
  • Image too small (< 200px in either dimension) — Facebook ignores these.
  • Image too big (> 8 MB) — most platforms time out and fall back to no image.
  • Image is a PNG with transparency — the alpha channel often renders as black on platforms that don't composite against a background.
Pro Tip — og:image:alt og:image:alt is supported by Facebook and a few others. Add it whenever the image conveys information not present in the title/description. Screen-reader users on social platforms will thank you.

6 Video & Audio OG Tags

If your page is about a video or audio resource, you can declare it as part of OG so platforms embed the media directly in the feed rather than just an image.

Video

<meta property="og:video" content="https://example.com/videos/intro.mp4">
<meta property="og:video:secure_url" content="https://example.com/videos/intro.mp4">
<meta property="og:video:type" content="video/mp4">
<meta property="og:video:width" content="1280">
<meta property="og:video:height" content="720">

For richer semantics, pair with og:type of video.movie, video.episode, video.tv_show, or video.other.

Audio

<meta property="og:audio" content="https://example.com/audio/podcast-ep-12.mp3">
<meta property="og:audio:secure_url" content="https://example.com/audio/podcast-ep-12.mp3">
<meta property="og:audio:type" content="audio/mpeg">
Reality check In practice, very few platforms render og:video or og:audio as inline players in the feed. Facebook and LinkedIn will often pick up the video. Twitter uses its own Twitter Player Card instead. Consider these tags as progressive enhancement.

7 Who Uses OG Tags

Facebook

The original creator. Reads all OG tags; renders full preview card with image.

LinkedIn

Full OG support. Particularly strict about image dimensions (must be ≥ 200×200).

Slack

Unfurls links using OG tags. Renders image, title, description in the channel.

Discord

Reads OG tags. Uses og:site_name as a footer label.

iMessage / Apple Messages

Renders rich preview when a URL is sent in a message bubble.

Telegram

Reads OG tags, including video tags for inline preview.

WhatsApp

Renders preview cards from OG tags.

Twitter/X

Reads OG tags as a fallback when Twitter Card tags aren't present.

Microsoft Teams

Unfurls links via OG tags in chat.

Pinterest

Uses og:image as the pin image when users save the page.

Reddit

Uses OG tags for link previews in posts.

GitHub

Uses OG tags for repository README links shared in issues.

8 Testing & Debugging

Facebook Sharing Debugger

Facebook's official tool at developers.facebook.com/tools/debug/ is the gold-standard OG tester. Paste your URL and it will:

  • Show the preview card exactly as Facebook will render it.
  • Report which OG tags were detected.
  • Report warnings (e.g., "image too small", "missing og:url").
  • Let you force a re-scrape (Facebook caches OG data aggressively — sometimes for days).

Other testing tools

LinkedIn Post Inspector

linkedin.com/post-inspector/ — shows the LinkedIn preview and forces a re-scrape.

Twitter Card Validator

cards-dev.twitter.com/validator — also validates OG fallbacks.

OpenGraph.xyz

A free meta-tag previewer that shows how your URL looks across 10+ platforms.

HeyMeta.com

Quick OG tag visualizer.

MetaTags.io

Live previewer with side-by-side mockups for FB, Twitter, LinkedIn, Slack.

curl + grep

The fastest debugging: curl -s example.com | grep 'og:' shows what's actually being served.

Common Mistake — stale cache You updated your OG tags but Facebook still shows the old preview? Facebook caches aggressively. Visit the Sharing Debugger and click "Scrape Again" to force a refresh. Same with LinkedIn Post Inspector.

9 Full Example

A complete OG setup for a blog article:

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>The Hitchhiker's Guide to HTML — The Daily Probe</title>
  <meta name="description" content="A complete tutorial covering everything from DOCTYPE to Web Components.">

  <!-- Open Graph -->
  <meta property="og:type" content="article">
  <meta property="og:site_name" content="The Daily Probe">
  <meta property="og:title" content="The Hitchhiker's Guide to HTML">
  <meta property="og:description" content="A complete tutorial covering everything from DOCTYPE to Web Components.">
  <meta property="og:url" content="https://example.com/posts/html-guide">
  <meta property="og:image" content="https://example.com/og/html-guide-cover.jpg">
  <meta property="og:image:secure_url" content="https://example.com/og/html-guide-cover.jpg">
  <meta property="og:image:type" content="image/jpeg">
  <meta property="og:image:width" content="1200">
  <meta property="og:image:height" content="630">
  <meta property="og:image:alt" content="Stylized cover showing the title over a starfield">
  <meta property="og:locale" content="en_US">
  <meta property="og:locale:alternate" content="fr_FR">
  <meta property="article:published_time" content="2024-03-15T08:00:00Z">
  <meta property="article:modified_time" content="2024-03-16T10:30:00Z">
  <meta property="article:author" content="https://example.com/authors/jane">
  <meta property="article:section" content="Web">
  <meta property="article:tag" content="HTML">
  <meta property="article:tag" content="tutorial">

  <!-- Twitter Card (covered in next lesson) -->
  <meta name="twitter:card" content="summary_large_image">
  <meta name="twitter:title" content="The Hitchhiker's Guide to HTML">
  <meta name="twitter:description" content="A complete tutorial covering everything from DOCTYPE to Web Components.">
  <meta name="twitter:image" content="https://example.com/og/html-guide-cover.jpg">

  <!-- Canonical -->
  <link rel="canonical" href="https://example.com/posts/html-guide">
</head>

10 Try It Yourself

Exercise 1 — Add OG to a page Pick any page you've built. Add the four required OG tags (og:title, og:type, og:image, og:url) plus og:description and og:site_name. Validate it at developers.facebook.com/tools/debug/.
Exercise 2 — Build an OG image Create an image at exactly 1200 × 630 px in your favorite image editor (or use a tool like Cloudinary, Bannerbear, or imgix). The image should include the article title prominently — most users will see it thumbnail-sized in their feed, so 60pt+ text is recommended.
Exercise 3 — Article-specific tags Add article:published_time, article:modified_time, article:author, and two article:tag entries to your page. Re-test in the Facebook debugger to confirm they appear.
Exercise 4 — Product page OG Build a simple product page with og:type="product" plus product:price:amount, product:price:currency, and product:availability. Test that the price shows up in the Facebook preview (note: Facebook has been de-emphasizing product OG support; LinkedIn is more reliable here).

11 Real-World Use Cases

Blog posts & news articles

Every content site needs OG tags so articles look good when shared on social media.

E-commerce product pages

OG image shows the product; product OG tags carry price and availability.

Documentation sites

Each doc page should have unique OG tags so links shared in Slack/Discord show useful context.

Marketing landing pages

Brand campaigns live or die by shareable preview cards.

Event pages

Conference, webinar, or meetup landing pages need eye-catching OG images to drive registrations via social shares.

User profiles

Profile pages with og:type="profile" render nicely when shared on social platforms.
