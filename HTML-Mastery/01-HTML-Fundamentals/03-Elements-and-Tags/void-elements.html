Void Elements

1 What Makes an Element Void?

A void element (sometimes called an "empty element" or "self-closing element") is an HTML element that:

  • Has no content — there is nothing between an opening and closing tag.
  • Has no closing tag in HTML5.
  • Cannot have child elements.

Void elements exist because they represent something that doesn't wrap content: an image is a single thing, not a container. A line break is a single event. A meta tag is a metadata point.

<!-- HTML5 style: no slash -->
<br>

<!-- XHTML style: with slash (still valid in HTML5) -->
<br />

Both forms parse identically. The trailing slash is ignored by HTML5 parsers.

2 The Complete List of Void Elements

There are exactly 13 void elements in HTML5. Memorise them:

ElementPurpose
<area>Clickable region in an image map
<base>Default URL/target for the page
<br>Line break
<col>Column in a table
<embed>External embedded content (e.g. PDF, plugin)
<hr>Horizontal rule / thematic break
<img>Image
<input>Form input control
<link>Link to external resource (CSS, favicon)
<meta>Metadata
<source>Media source inside <video>/<audio>/<picture>
<track>Text track (subtitles, captions) for media
<wbr>Word break opportunity
Pro Tip — Mnemonic Try this memory aid: "ABCE HI LM ST W" → Area, Base, Col, Embed, HR, Img, Input, Link, Meta, Source, Track, Wbr. Or just remember that all void elements represent a single "thing" rather than a container.

3 <br> — Line Break

Forces a line break in text. Useful for poetry, addresses, and other content where line divisions matter.

<p>
  Roses are red,<br>
  Violets are blue,<br>
  HTML is marvellous,<br>
  And so are you.
</p>

Roses are red,
Violets are blue,
HTML is marvellous,
And so are you.

Common Mistake Don't use <br> to create space between paragraphs. Use multiple <p> elements with CSS margin instead. <br> is for content-driven line breaks only. 
<!-- BAD: using br for spacing -->
<p>First paragraph</p><br><br><br>
<p>Second paragraph</p>

<!-- GOOD: use CSS margins -->
<p>First paragraph</p>
<p>Second paragraph</p>
<!-- CSS: p { margin-bottom: 1.5em; } -->

4 <hr> — Horizontal Rule

Represents a thematic break — a transition between topics. Despite the name, it's not just decorative; it carries semantic meaning.

<h2>Chapter 1</h2>
<p>The dragon slept...</p>

<hr>

<h2>Chapter 2</h2>
<p>Years later...</p>

Chapter 1

The dragon slept...

Chapter 2

Years later...

Style with CSS: hr { border: none; border-top: 2px solid #ccc; margin: 2em 0; }

5 <img> — Image

Embeds an image. src is required; alt is required for accessibility (use empty alt="" only for purely decorative images).

<img
  src="photo.jpg"
  alt="A golden retriever catches a frisbee mid-air"
  width="400"
  height="300"
  loading="lazy"
  decoding="async"
>

Key attributes:

  • src — image URL (required)
  • alt — text alternative (required for accessibility)
  • width, height — intrinsic dimensions (prevents layout shift)
  • loading="lazy" — defer loading until near viewport
  • decoding="async" — decode off the main thread
  • sizes, srcset — responsive image hints

6 <input> — Form Input

The most attribute-rich void element. Different type values create very different controls.

<label for="name">Name:</label>
<input type="text" id="name" name="name" required>

<label for="email">Email:</label>
<input type="email" id="email" name="email" required autocomplete="email">

<label for="pwd">Password:</label>
<input type="password" id="pwd" name="pwd" minlength="8" required>

<input type="checkbox" id="agree" name="agree" required>
<label for="agree">I agree to the terms</label>

<input type="radio" id="r1" name="plan" value="basic">
<label for="r1">Basic</label>

<input type="range" min="0" max="100" value="50">

<input type="color" value="#2563eb">

<input type="date" min="2024-01-01">

<input type="file" accept="image/*" multiple>

<input type="submit" value="Send">

The type attribute can be: text, email, password, number, tel, url, search, date, datetime-local, time, month, week, color, range, checkbox, radio, file, hidden, submit, reset, button, image.

7 <meta> — Metadata

Page-level metadata. Always inside <head>. Multiple per page are normal.

<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<meta name="description" content="A complete HTML course.">
<meta name="author" content="Jane Doe">
<meta name="robots" content="index, follow">
<meta property="og:title" content="HTML Mastery">
<meta http-equiv="refresh" content="30">

See the Metadata page for the full treatment.

8 <link> — External Resource

Links to an external resource. The most common use is loading stylesheets, but it also handles favicons, preconnect hints, and more.

<!-- Stylesheet -->
<link rel="stylesheet" href="/styles.css">

<!-- Favicon -->
<link rel="icon" href="/favicon.ico">
<link rel="apple-touch-icon" href="/apple-touch-icon.png" sizes="180x180">
<link rel="manifest" href="/manifest.webmanifest">

<!-- Performance hints -->
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="dns-prefetch" href="https://fonts.gstatic.com">
<link rel="preload" href="/hero.jpg" as="image">
<link rel="prefetch" href="/next-page.html">

<!-- RSS / Atom feed -->
<link rel="alternate" type="application/rss+xml" href="/feed.xml">

9 <area> — Image Map Region

Defines a clickable region inside an image map. Used inside <map>.

<img src="planets.png" usemap="#planetmap" alt="Planets">

<map name="planetmap">
  <area shape="circle" coords="90,58,30" alt="Mercury" href="mercury.html">
  <area shape="circle" coords="180,58,30" alt="Venus" href="venus.html">
  <area shape="rect" coords="0,0,82,126" alt="Sun" href="sun.html">
  <area shape="poly" coords="100,50,150,80,120,120" alt="Mars" href="mars.html">
</map>

Shape values: rect, circle, poly, default (whole image). Image maps are largely obsolete today; CSS-positioned links over images are usually better. But <area> still has niche uses.

10 <base> — Default URL/Target

Sets the base URL for all relative URLs on the page, and optionally the default target for links.

<head>
  <base href="https://example.com/blog/" target="_blank">
</head>
<body>
  <!-- Now this resolves to https://example.com/blog/post-1.html -->
  <a href="post-1.html">Post 1</a>

  <!-- And this image comes from https://example.com/blog/img/photo.jpg -->
  <img src="img/photo.jpg" alt="">
</body>
Common Mistake <base> affects every relative URL on the page, including ones you didn't intend (like anchors <a href="#"> which become https://example.com/blog/#). It's a footgun. Use sparingly.

11 <col> — Table Column

Defines properties for a column in a table. Used inside <colgroup>.

<table>
  <colgroup>
    <col style="background-color:#f0f9ff">
    <col style="background-color:#fef3c7">
    <col style="background-color:#fee2e2">
  </colgroup>
  <tr>
    <th>Name</th>
    <th>Email</th>
    <th>Status</th>
  </tr>
  <tr>
    <td>Jane</td>
    <td>j@x.com</td>
    <td>Active</td>
  </tr>
</table>

<col> can apply a few CSS properties (background, width, border, visibility) to an entire column at once — much cleaner than repeating classes on every cell.

12 <embed> — External Content

Embeds external content that requires a plugin or a viewer. Largely replaced by <object>, <iframe>, <video>, and <audio>, but still has uses for PDFs and SVG.

<embed src="document.pdf" type="application/pdf" width="800" height="600">
<embed src="animation.svg" type="image/svg+xml">

The WHATWG spec keeps <embed> for backward compatibility. For new projects, prefer <iframe> or <object>.

13 <source> — Media Source

Specifies multiple media sources so the browser can pick one it supports. Used inside <video>, <audio>, and <picture>.

<picture>
  <source srcset="wide.jpg" media="(min-width: 800px)">
  <source srcset="narrow.jpg">
  <img src="default.jpg" alt="...">
</picture>

<video controls>
  <source src="movie.mp4" type="video/mp4">
  <source src="movie.webm" type="video/webm">
  Your browser does not support the video tag.
</video>

<audio controls>
  <source src="song.mp3" type="audio/mpeg">
  <source src="song.ogg" type="audio/ogg">
</audio>

The browser picks the first source it can play. Always provide a fallback after the <source> tags.

14 <track> — Subtitles/Captions

Provides timed text tracks for <video> and <audio>: subtitles, captions, descriptions, chapters, metadata.

<video controls>
  <source src="movie.mp4" type="video/mp4">
  <track kind="subtitles" src="subtitles.en.vtt" srclang="en" label="English">
  <track kind="subtitles" src="subtitles.es.vtt" srclang="es" label="Spanish">
  <track kind="captions" src="captions.en.vtt" srclang="en" label="English captions">
</video>

kind values: subtitles (translation), captions (transcription with sound effects), descriptions (for visually impaired), chapters (navigation), metadata (for scripts).

Track files use the WebVTT format.

15 <wbr> — Word Break Opportunity

Tells the browser "if you need to wrap here, you may". Useful for long URLs or code that shouldn't break mid-word but should wrap at sensible points.

<p>
  Learn more at https://example.com<wbr>/very-long-url<wbr>/that-might-overflow<wbr>/the-container
</p>

Without <wbr>, long unbroken strings can overflow the page horizontally. With <wbr>, the browser breaks only when necessary.

Long URL: https://example.com/very-long-url/that-might-overflow/the-container

16 The Trailing Slash Question

Should you write <br> or <br />? Both are valid HTML5. The choice is a style preference.

StyleOriginUsed by
<br>HTML5Most modern projects, WHATWG spec, MDN
<br />XHTMLReact (JSX requires it), legacy code, WordPress

The HTML5 spec says: "Then, if the element is one of the void elements… the trailing slash has no effect." So pick one and be consistent.

Common Mistake Don't try to self-close non-void elements. <div /> does NOT mean an empty div in HTML — it's parsed as an opening tag for <div> with a trailing slash attribute (which is ignored), and the div remains open. Always write <div></div>.
Try it yourself — 10 minutes Create a single HTML file that uses at least 8 of the 13 void elements. Suggested content:
  1. A <meta charset> and viewport.
  2. A linked stylesheet via <link>.
  3. An image via <img>.
  4. A horizontal rule via <hr>.
  5. A poem with line breaks via <br>.
  6. A form with at least three <input> fields.
  7. A table using <col> for column styling.
  8. A long URL using <wbr> for break opportunities.
  9. A <video> with two <source> elements and a <track>.
Validate the result at validator.w3.org. If you used all 9 correctly, the validator will pass.
