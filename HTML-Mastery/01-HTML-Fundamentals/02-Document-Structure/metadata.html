1 What Is Metadata?

Metadata is data about the document. It lives in the <head> and is not rendered as visible content. The <meta> element is the workhorse — a void element that carries name/value pairs.

The general form is one of two patterns:

<!-- Pattern 1: name + content -->
<meta name="description" content="A description of the page.">

<!-- Pattern 2: http-equiv + content (acts like an HTTP header) -->
<meta http-equiv="refresh" content="30">

<!-- Pattern 3: charset (special) -->
<meta charset="UTF-8">

<!-- Pattern 4: property + content (Open Graph etc.) -->
<meta property="og:title" content="My Page">

2 Character Encoding (charset)

The single most important meta tag. Declares how the bytes in your file map to characters.

<meta charset="UTF-8">

Without it, browsers guess. They usually guess wrong for non-ASCII characters — é, ñ, 漢, emoji — and your page fills with â€™ garbage.

Rules:

  • Use UTF-8. Always. It supports every character in every language.
  • Place it within the first 1024 bytes of the file (the spec recommends it be in the first 512).
  • It should be the first child of <head>.
  • Only one <meta charset> per document.
Common Mistake If you save your HTML file with one encoding (say, UTF-8) but declare a different charset in the meta tag (say, ISO-8859-1), characters will render wrong. Make sure your editor saves as UTF-8 — most do by default.

3 Viewport

Controls how the page is sized on mobile devices. Without it, mobile browsers shrink a desktop layout to fit a 980px-wide virtual viewport, making text unreadably small.

<meta name="viewport" content="width=device-width, initial-scale=1.0">

Breaking down the content value:

  • width=device-width — make the layout viewport equal to the device's physical width.
  • initial-scale=1.0 — start at 100% zoom.
  • Optional: maximum-scale=5 — limit zoom out.
  • Optional: user-scalable=no — disable pinch zoom. Don't do this; it's an accessibility violation.
Common Mistake Setting user-scalable=no or maximum-scale=1.0 prevents users with low vision from zooming. The WCAG accessibility guidelines explicitly forbid this. Just don't.

4 Description & Keywords

Description

<meta name="description" content="A complete, beginner-to-expert guide to HTML. Learn structure, semantics, forms, accessibility, and best practices with hands-on exercises.">

The description is what Google shows under your title in search results (usually). It is the second-most-important meta tag for SEO after the <title>.

Rules:

  • Keep it under ~155 characters (Google truncates longer).
  • Write for humans — it's the elevator pitch for your page.
  • Include the primary keyword naturally.
  • One per page. Each page should have a unique description.

Keywords

<meta name="keywords" content="html, html5, learn html, web development">

Google ignores the keywords meta tag entirely. It was abused so heavily in the 2000s that search engines dropped it. Bing also ignores it. You can include it for historical completeness or internal tooling, but it has zero SEO value.

Pro Tip Don't waste time on the keywords meta. Spend that time writing a better description.

5 Author & Generator

<meta name="author" content="Jane Doe">
<meta name="generator" content="Hugo 0.110.0">
<meta name="application-name" content="MyApp">
<meta name="copyright" content="© 2024 Acme Inc.">

These are informational. generator is often auto-added by CMSes like WordPress. author is occasionally used by search engines or readers. None affect ranking.

6 Robots

The robots meta tag tells search engines what to do with the page.

<!-- Index this page and follow its links (default) -->
<meta name="robots" content="index, follow">

<!-- Don't index, don't follow links -->
<meta name="robots" content="noindex, nofollow">

<!-- Index but don't follow links -->
<meta name="robots" content="index, nofollow">

<!-- Don't index but follow links (useful for thin pages) -->
<meta name="robots" content="noindex, follow">

<!-- Don't show a cached copy in results -->
<meta name="robots" content="noarchive">

<!-- Don't use this page to create a snippet -->
<meta name="robots" content="nosnippet">

<!-- Limit snippet to 50 characters -->
<meta name="robots" content="max-snippet:50">

<!-- Don't index images on this page -->
<meta name="robots" content="noimageindex">

Common values: index, noindex, follow, nofollow, noarchive, nosnippet, noimageindex, unavailable_after.

Common Mistake The robots meta is a request, not a command. Major search engines respect it, but rogue bots ignore it. Don't rely on noindex to hide sensitive data — protect it with authentication instead.

7 http-equiv

The http-equiv attribute lets a meta tag act like an HTTP response header. The browser treats the content value as if the server had sent it in the response headers.

<!-- Force standards mode in old IE (modern IE ignores) -->
<meta http-equiv="X-UA-Compatible" content="IE=edge">

<!-- Declare content security policy -->
<meta http-equiv="Content-Security-Policy"
      content="default-src 'self'; img-src 'self' data:;">

<!-- Set a cookie (deprecated; prefer Set-Cookie header) -->
<meta http-equiv="Set-Cookie" content="session=abc123; Path=/; HttpOnly">

<!-- Default style (for <link rel="alternate stylesheet">) -->
<meta http-equiv="default-style" content="preferred-theme">

<!-- Content type (rare in HTML5, since charset does this) -->
<meta http-equiv="Content-Type" content="text/html; charset=UTF-8">

8 Refresh & Redirect

The refresh directive tells the browser to reload the page or redirect to a new URL after a delay.

<!-- Refresh this page every 60 seconds (e.g. live scores) -->
<meta http-equiv="refresh" content="60">

<!-- Redirect to /new-page after 5 seconds -->
<meta http-equiv="refresh" content="5; url=/new-page/">

<!-- Immediate redirect (0 second delay) -->
<meta http-equiv="refresh" content="0; url=/login/">
Common Mistake Meta refresh is generally a bad pattern:
  • It's slow — users see the original page flash before redirect.
  • It breaks the browser's Back button.
  • Search engines prefer server-side 301/302 redirects.
Use a server-side redirect whenever possible. Meta refresh is a fallback only.

9 Theme Color

Tints the browser chrome (address bar, status bar) on mobile devices. Lovely for branded mobile web apps.

<meta name="theme-color" content="#2563eb">

<!-- Adaptive: dark mode-aware -->
<meta name="theme-color" content="#ffffff" media="(prefers-color-scheme: light)">
<meta name="theme-color" content="#0f172a" media="(prefers-color-scheme: dark)">

<!-- Also: color-scheme lets the browser pick default form control colors -->
<meta name="color-scheme" content="dark light">

Supported in Chrome on Android, Samsung Internet, and Edge. Not supported in iOS Safari (Apple doesn't tint the chrome).

10 Open Graph (Facebook, LinkedIn, etc.)

Open Graph tags (the og: prefix, originally from Facebook) control how your page appears when shared on social media. They are essential for any page you expect to be linked.

<!-- Required: title, type, image, url -->
<meta property="og:title" content="How to Bake Sourdough Bread">
<meta property="og:type" content="article">
<meta property="og:url" content="https://example.com/blog/sourdough">
<meta property="og:image" content="https://example.com/img/sourdough.jpg">
<meta property="og:image:width" content="1200">
<meta property="og:image:height" content="630">
<meta property="og:image:alt" content="A loaf of fresh sourdough bread on a wooden board">

<!-- Optional but recommended -->
<meta property="og:description" content="A step-by-step guide to baking sourdough at home.">
<meta property="og:site_name" content="Example Bakery">
<meta property="og:locale" content="en_US">
<meta property="og:locale:alternate" content="fr_FR">

<!-- For articles specifically -->
<meta property="article:published_time" content="2024-03-15T08:00:00Z">
<meta property="article:author" content="Jane Doe">
<meta property="article:section" content="Baking">
<meta property="article:tag" content="bread">
<meta property="article:tag" content="sourdough">

Recommended image size

1200 × 630 pixels. Larger images are cropped; smaller images look bad. Use JPEG for photos, PNG for graphics.

Pro Tip Test your Open Graph tags with the Facebook Sharing Debugger and LinkedIn Post Inspector before publishing. Both will fetch your tags and show you the preview card.

11 Twitter Cards

Twitter has its own meta tags for richer previews. They overlap with Open Graph; Twitter will fall back to OG if Twitter tags are missing.

<meta name="twitter:card" content="summary_large_image">
<meta name="twitter:site" content="@examplebakery">
<meta name="twitter:creator" content="@janedoe">
<meta name="twitter:title" content="How to Bake Sourdough Bread">
<meta name="twitter:description" content="A step-by-step guide.">
<meta name="twitter:image" content="https://example.com/img/sourdough.jpg">
<meta name="twitter:image:alt" content="A loaf of sourdough on a wooden board">

Card types: summary (small square image), summary_large_image (large featured image), player (for video/audio), app (mobile app).

12 Lesser-Known Metas

<!-- Prevent referer leak when leaving your site -->
<meta name="referrer" content="no-referrer">
<meta name="referrer" content="origin-when-cross-origin">

<!-- Format detection: stop iOS from auto-linking phone numbers -->
<meta name="format-detection" content="telephone=no">

<!-- Apple touch icon (iOS home screen icon) -->
<link rel="apple-touch-icon" href="/apple-touch-icon.png">
<link rel="apple-touch-icon" sizes="180x180" href="/apple-touch-icon-180.png">

<!-- iOS web app capabilities -->
<meta name="apple-mobile-web-app-capable" content="yes">
<meta name="apple-mobile-web-app-status-bar-style" content="black-translucent">
<meta name="apple-mobile-web-app-title" content="MyApp">

<!-- Android PWA manifest (better in a manifest.json file) -->
<link rel="manifest" href="/manifest.webmanifest">

<!-- Windows tile (legacy, for IE11 pinned sites) -->
<meta name="application-name" content="MyApp">
<meta name="msapplication-TileColor" content="#2563eb">
<meta name="msapplication-square150x150logo" content="/mstile-150.png">

<!-- Pinned site color in Windows -->
<meta name="msapplication-navbutton-color" content="#2563eb">

<!-- Disable automatic detection of email-style links on iOS -->
<meta name="format-detection" content="address=no">

<!-- Page expiry (cache control hint, prefer HTTP headers) -->
<meta http-equiv="Expires" content="Wed, 21 Oct 2025 07:28:00 GMT">

<!-- Inline JSON-LD structured data (better SEO) -->
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Article",
  "headline": "How to Bake Sourdough Bread",
  "author": { "@type": "Person", "name": "Jane Doe" }
}
</script>

13 Order Matters

The HTML5 spec says the page's character encoding declaration must appear within the first 1024 bytes — so <meta charset> should be the first child of <head>. Beyond that, the order is mostly aesthetic. A sensible order:

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Page Title — Site Name</title>
  <meta name="description" content="...">

  <!-- Performance hints first -->
  <link rel="preconnect" href="https://cdn.example.com">
  <link rel="preload" as="image" href="/hero.jpg">

  <!-- Stylesheets -->
  <link rel="stylesheet" href="/styles.css">

  <!-- Icons -->
  <link rel="icon" href="/favicon.ico">
  <link rel="apple-touch-icon" href="/apple-touch-icon.png">

  <!-- Social sharing -->
  <meta property="og:title" content="...">
  <meta property="og:image" content="...">
  <meta name="twitter:card" content="summary_large_image">

  <!-- Robots -->
  <meta name="robots" content="index, follow">

  <!-- Theme color -->
  <meta name="theme-color" content="#2563eb">

  <!-- Deferred JS -->
  <script src="/app.js" defer></script>
</head>

14 Common Mistakes

MistakeFix
Forgetting <meta charset>Add <meta charset="UTF-8"> as the first child of <head>.
Forgetting viewportPages look tiny on mobile. Always add the viewport meta.
Description over 160 charsGoogle truncates. Keep it 50–155.
Using keywords meta for SEOIt does nothing. Remove it.
OG image missingPages share without a preview image. Always set og:image.
Theme color too saturatedA bright red address bar is jarring. Pick a brand-appropriate colour.
Multiple charset metasInvalid. Only one allowed.
Using meta refresh for redirectsUse server-side 301 redirects instead.
Setting user-scalable=noAccessibility violation. Never set it.
Putting meta tags in <body>Move to <head>.
