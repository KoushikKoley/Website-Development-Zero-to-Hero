Section 1.1 · History

The History of HTML

From a Swiss physics lab in 1989 to a Living Standard maintained by an open community today — three decades of decisions that shape every web page you've ever visited.

1 The Origin: 1989, CERN

In March 1989, a 33-year-old British physicist named Tim Berners-Lee working at CERN (the European Organization for Nuclear Research, near Geneva, Switzerland) wrote a proposal titled "Information Management: A Proposal". His boss, Mike Sendall, scrawled in the margin: "Vague but exciting…"

Berners-Lee's problem was mundane but real: CERN had thousands of researchers coming and going, each with their own documents, notes, and findings. Finding information was hard. His proposed solution was a "mesh" of linked documents — what he later renamed the World Wide Web.

The three inventions he proposed remain the foundation of the modern web:

URL

Uniform Resource Locator — a way to address any document on the network.

HTTP

HyperText Transfer Protocol — a way to request documents.

HTML

HyperText Markup Language — a way to write documents with links.

Browser/Server

The first browser (named "WorldWideWeb") and the first web server (named "httpd") both written by Berners-Lee.

The first website went live on 6 August 1991 at http://info.cern.ch — it still exists today and you can visit it. It explained what the World Wide Web was, how to get a browser, and how to set up your own server.

Pro Tip You can visit the world's first website at info.cern.ch. Look at the source — it's a tiny HTML document. You can read it in 30 seconds.

2 HTML 1.0 (1993)

The first informal HTML specification was published in 1993 by Tim Berners-Lee and Dan Connolly. HTML 1.0 was tiny — only about 18 elements. There were no tables, no forms, no images embedded in pages, no colours, no CSS. The original vision was for HTML to be a way to share scientific papers.

HTML 1.0 included:

  • Headings: <h1> through <h6>
  • Paragraphs: <p>
  • Links: <a href="...">
  • Lists: <ul>, <ol>, <li>
  • Address: <address>
  • Term/definition lists: <dl>
  • Preformatted text: <pre>
  • Title: <title>
<!-- A 1993-era HTML document would look like this -->
<TITLE>My Research Paper</TITLE>
<H1>Abstract</H1>
<P>This paper examines the viscosity of quark-gluon plasma.
<P>See <A HREF="paper2.html">related work</A>.
<UL>
  <LI>Introduction
  <LI>Method
  <LI>Results
</UL>

Note that HTML 1.0 didn't even require <html>, <head>, or <body> tags. They were implied. And tags were case-insensitive (most people used UPPERCASE for clarity).

3 HTML 2.0 (1995)

The Internet Engineering Task Force (IETF) published HTML 2.0 as RFC 1866 in November 1995. HTML 2.0 didn't add much that was new — it formalised what browsers were already doing — but it added one crucial feature: forms.

With forms came <form>, <input>, <textarea>, <select>, <option>. For the first time, web pages could collect user input. This unlocked the modern interactive web.

HTML 2.0 also added <img> — the inline image. The original proposal was for a more powerful <FIG> element with captions and credits, but it was deemed too complex. <img> won by being simpler.

4 HTML 3.2 (1997)

By 1996, the browser wars between Netscape Navigator and Internet Explorer had produced a messy landscape. Both browsers had added their own proprietary tags (<blink>, <marquee>, <font>, <center>, <table> with various extensions). HTML 3.2 was the W3C's compromise — it formalised many of these tags, including presentation tags that we now consider harmful.

HTML 3.2 added:

  • Tables: <table>, <tr>, <td>, <th>, <caption>
  • Image maps: <map>, <area>
  • Presentation tags: <font>, <center>, <big>, <small>, <u>, <strike>
  • Scripting hooks: <script> and <style> were officially recognised
Common Mistake Many tutorials still teach <font> and <center>. They are obsolete in HTML5 — they still work but they mix presentation with structure, which is exactly what CSS was invented to fix. Use CSS instead.

5 HTML 4.01 (1999)

HTML 4.01, released in December 1999, was the most important pre-HTML5 release. It introduced the modern principle of separating structure from presentation. Three "flavours" of HTML 4.01 were defined:

FlavourMeaning
StrictNo presentational tags. Pure structure. The recommended flavour.
TransitionalAllowed presentational tags like <font>. For legacy sites.
FramesetAllowed the dreaded <frameset> element for splitting windows into frames.

HTML 4.01 doctypes were infamously long:

<!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 4.01//EN"
   "http://www.w3.org/TR/html4/strict.dtd">

HTML 4.01 also formally introduced accessibility as a goal, with the alt attribute on images becoming mandatory in the Strict flavour.

6 XHTML 1.0 (2000)

In January 2000 the W3C published XHTML 1.0. XHTML was HTML rewritten as XML. The idea was that XML's strict parsing rules would force authors to write cleaner code, and that XML tooling could be applied to web content.

XHTML demanded:

  • All tags lowercase: <P> → <p>
  • All attributes quoted: <a href=x> → <a href="x">
  • All elements closed: <br> → <br />
  • All elements properly nested
  • One root <html> element

XHTML failed in the market. The reason was brutal: a single syntax error (a missing /) would cause Internet Explorer to display a blank page with an error message. Real-world content is messy; XML's strictness was unrealistic. By 2007, the industry had largely abandoned XHTML.

Common Mistake You may see old code with <br /> or <img ... /> — the trailing slash is an XHTML convention. It's still valid in HTML5 (parsers ignore the slash on void elements) but unnecessary. Pick a style and be consistent.

7 HTML5 (2014)

HTML5 didn't appear in a single release — it was a multi-year effort (2007–2014) by a group called the Web Hypertext Application Technology Working Group (WHATWG). HTML5 abandoned the "version" model entirely; it's a living language. But the term "HTML5" stuck as a marketing label.

HTML5 added a huge amount:

Semantic elements

<header>, <footer>, <nav>, <article>, <section>, <aside>, <main>, <figure>, <time>.

Media elements

<audio> and <video> — no plugins required.

Canvas & SVG

<canvas> for 2D drawing; native SVG support.

Form input types

email, url, date, number, range, color, etc.

Native APIs

Geolocation, localStorage, Web Workers, WebSockets, drag-and-drop.

Simple doctype

<!DOCTYPE html> — five characters instead of 100.

HTML5 also formalised the principle that browsers should be forgiving — they should try to render any input rather than reject it. This is called "error recovery" and it's why HTML5 works on the messy real-world web.

8 WHATWG vs W3C

The history of HTML since 2004 has been shaped by a polite but real rivalry between two standards bodies:

W3CWHATWG
Founded1994 by Tim Berners-Lee2004 by Apple, Mozilla, Opera
ModelSnapshot versions (HTML 4.01, 5.0, 5.1, 5.2, …)Single Living Standard, continually updated
PhilosophyTop-down, formalisedBottom-up, browser-driven
MembersPaid membership organisationsOpen to anyone

From 2007 to 2018, both bodies worked on HTML in parallel, occasionally diverging. In May 2019, the W3C formally handed over HTML to the WHATWG. Today there is one HTML spec: the WHATWG HTML Living Standard. There will be no HTML6 — there will only be "HTML, current as of today".

Pro Tip When looking up an HTML feature, prefer the WHATWG spec or MDN over W3Schools or any "HTML5 reference" site from before 2019. Old references may describe behaviours that have since changed.

9 The Living Standard Today

The HTML Living Standard is updated continuously — often multiple times per week. New elements appear, old ones are deprecated, and behaviors are refined. There is no "HTML 6" or "HTML 5.3" — there's just the latest version of the spec, available at html.spec.whatwg.org.

Some recent additions include:

  • <dialog> — native modal dialogs (2022)
  • <details>/<summary> — native disclosure widgets
  • The popover attribute — declarative popovers (2023)
  • loading="lazy" on images and iframes
  • <search> element (2023)
  • Declarative shadow DOM
Common Mistake Don't think of "HTML5" as a fixed feature set you check against a 2014 list. Check current browser support on caniuse.com and the spec at WHATWG.

10 Visual Timeline

1989

The Proposal

Tim Berners-Lee submits "Information Management: A Proposal" at CERN. Initial reaction: "vague but exciting".

1991

First Website Goes Live

August 6, 1991 — info.cern.ch explains the World Wide Web. The first public web page.

1993

HTML 1.0 Draft

Berners-Lee and Connolly publish the first informal HTML spec. ~18 elements. No images, no forms, no tables.

1994

W3C Founded

Tim Berners-Lee founds the World Wide Web Consortium (W3C) at MIT to coordinate web standards.

1995

HTML 2.0 (RFC 1866)

IETF publishes HTML 2.0. Adds <form>, <input>, <img>.

1997

HTML 3.2

Tables, image maps, and presentational tags (<font>, <center>) are formalised.

1999

HTML 4.01

Separates structure from presentation. Introduces Strict, Transitional, Frameset flavours.

2000

XHTML 1.0

HTML reformulated as XML. Strict syntax. Ultimately fails due to brittle parsing.

2004

WHATWG Founded

Apple, Mozilla, and Opera form WHATWG to push HTML forward outside the W3C.

2007

HTML5 Work Begins

W3C adopts WHATWG's HTML5 draft as the basis for the next version.

2014

"HTML5" Marketing Release

W3C publishes HTML5 as a single Recommendation. WHATWG continues as Living Standard.

2019

W3C Hands HTML to WHATWG

W3C and WHATWG sign an MoU: HTML and DOM are now exclusively the WHATWG Living Standard.

Today

Living Standard

HTML evolves continuously. New elements like <dialog>, <search>, and the popover attribute ship regularly.

Try it yourself — 10 minutes Visit info.cern.ch and view its source. Then visit a modern site (e.g. MDN) and view its source. List three differences in element names or structure. You're holding 35 years of evolution in your hands.
