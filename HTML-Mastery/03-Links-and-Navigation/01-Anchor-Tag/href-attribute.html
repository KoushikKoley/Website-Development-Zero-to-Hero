Section 3.2 · href Attribute

The href Attribute Deep Dive

The single most important attribute on an anchor. It accepts absolute URLs, relative URLs, fragments, mailto:, tel:, sms:, and more — but each has its own rules, security implications, and gotchas. Let's dissect them all.

1 What href Does

href (Hypertext REFerence) tells the browser where to navigate when the anchor is activated. Without href, an <a> is a placeholder — not focusable, not clickable, not announced as a link. With href, it becomes a fully functional hyperlink.

The value is a URL (Uniform Resource Locator), but URLs come in many flavors. The browser resolves the URL based on its syntax: scheme (https, mailto, tel), origin (host + port), path, query, and fragment.

Pro Tip When you omit href entirely, the <a> is treated as a placeholder link. This is sometimes used for the "current page" in navigation, but it's better to keep href and add aria-current="page" for accessibility.

2 URL Structure Anatomy

Every URL follows the same general structure. Understanding each part lets you read, debug, and construct URLs with confidence.

Common Mistake The fragment (#) is never sent to the server. If you rely on it for analytics, you'll miss the data. Use query params (?section=conclusion) or JavaScript (location.hash) to track fragment usage.

3 Absolute URLs

An absolute URL contains everything needed to locate the resource: scheme, host, and (optionally) port, path, query, and fragment. Use absolute URLs when linking to other websites, or when you want to be explicit about the protocol.

<!-- Standard https link -->
<a href="https://developer.mozilla.org/en-US/docs/Web/HTML">MDN HTML Docs</a>

<!-- Protocol-relative (//) — uses current page's scheme. DISCOURAGED. -->
<a href="//cdn.example.com/lib.js">CDN resource</a>

<!-- With port -->
<a href="https://localhost:3000/admin">Local admin</a>

<-- With query and fragment -->
<a href="https://search.example.com/q?term=css+grid&page=2#results">
  Search results
</a>
Common Mistake — Protocol-Relative URLs The //example.com/path syntax (protocol-relative) was popular when sites served both http: and https:. Now that HTTPS is universal, it's an anti-pattern: it inherits whatever scheme the page was loaded with, which can cause mixed-content failures or unexpected behavior on file://. Always use https:// explicitly.
Pro Tip — Always HTTPS Use https:// even for links to sites you don't control. Modern browsers will silently upgrade http:// to https:// via HSTS for major sites, but you can't rely on it. Default to HTTPS for every external link.

4 Relative URLs

Relative URLs are resolved against the current page's URL. They're shorter, more portable, and the standard for internal links. There are four flavors:

FormExampleResolves To (if current page is /blog/post.html)
Same-dir relativeabout.html or ./about.html/blog/about.html
Parent-dir relative../about.html/about.html
Root-absolute/about.html/about.html (resolves from domain root)
Empty"" or #Same page (current URL)
 
<!-- Same directory -->
<a href="contact.html">Contact</a>
<a href="./contact.html">Contact</a>  <!-- equivalent -->

<!-- Up one directory -->
<a href="../index.html">Home</a>

<!-- Up two directories, then into /products/ -->
<a href="../../products/widget.html">Widget</a>

<!-- Root-absolute (preferred for internal links) -->
<a href="/products">All Products</a>
<a href="/blog/2024/css-grid">CSS Grid Post</a>

<!-- Same page, jump to fragment -->
<a href="#top">Back to top</a>

<!-- Query only (modifies current page's query) -->
<a href="?page=2">Next page</a>
Pro Tip — Prefer Root-Absolute Use /products/widget (root-absolute) over ../../products/widget.html (parent-relative). Root-absolute paths survive file moves and are easier to read. The deep dive is in 02-URL-Types/absolute-relative.html.

5 Fragment Identifiers #id

A fragment — the part after # — identifies a specific element on the page by its id. Clicking such a link scrolls the page to that element (and updates location.hash).

<!-- Same page -->
<a href="#chapter-3">Skip to Chapter 3</a>

<!-- Cross-page fragment (jumps to #section on /about.html) -->
<a href="/about.html#team">Meet the team</a>

<!-- Target element -->
<section id="chapter-3">
  <h2>Chapter 3: Closing the Loop</h2>
  <p>...</p>
</section>

Fragments don't trigger a server request — they're handled client-side. The browser scrolls the matched element into view and updates the URL. CSS scroll-behavior: smooth and the :target pseudo-class give you CSS-only control over the experience.

Pro Tip Always use :target to highlight the section the user just jumped to. It's free UX: :target { background: #fef9c3; transition: background 1s; }

The full fragment deep dive (smooth scrolling, :target, skip links) is in 02-URL-Types/fragments.html.

6 mailto: Scheme

Opens the visitor's default email client with a pre-filled message. Supports multiple recipients, subject, body, cc, and bcc via query-string-style parameters.

<!-- Simple -->
<a href="mailto:hello@example.com">Email us</a>

<!-- Multiple recipients -->
<a href="mailto:alice@example.com,bob@example.com">Email both</a>

<-- With cc and bcc -->
<a href="mailto:hello@example.com?cc=sales@example.com&bcc=boss@example.com">
  Email with cc/bcc
</a>

<-- With subject and body -->
<a href="mailto:hello@example.com?subject=Hello&body=I%20have%20a%20question%20about...">
  Send a question
</a>
Click to compose an email →
Common Mistake — URL Encoding Spaces and special characters in subject/body must be percent-encoded: %20 for space, %0D%0A for newline, %3F for ?, %26 for &. Otherwise the mail client will misparse the parameters.

Full coverage in 04-Download-Links/email-tel-links.html.

7 tel: Scheme

On mobile (and many desktops with calling apps), tel: opens the dialer with the number pre-filled. Always use the international format starting with +.

<!-- International format (recommended) -->
<a href="tel:+18005551234">+1 (800) 555-1234</a>

<!-- Display formatting is fine — but the tel: value should be E.164 -->
<a href="tel:+442071838750">Call our London office: 020 7183 8750</a>

<-- With pause (comma) — useful for extensions -->
<a href="tel:+18005551234,1234">Call support, then ext. 1234</a>
📞 Call us: +1 (800) 555-1234
Pro Tip Always include + and the country code in tel:. A visitor from another country dialing 020 7183 8750 directly will fail; +44 20 7183 8750 works globally.

8 sms: Scheme

Opens the SMS app with a number (and optionally a pre-filled body on some platforms). Support is inconsistent across browsers and OSes.

<!-- Open SMS app with number filled in -->
<a href="sms:+18005551234">Text us</a>

<-- Android: pre-fill body with ?body= -->
<a href="sms:+18005551234?body=I%20want%20to%20opt%20in">Text OPTIN to subscribe</a>

<-- iOS: pre-fill body with &body= -->
<a href="sms:+18005551234&body=I%20want%20to%20opt%20in">Text OPTIN to subscribe</a>
Common Mistake — Inconsistent Syntax iOS uses &body=; Android historically used ?body=. There's no universal syntax. For reliability, link just the number (sms:+18005551234) and put the message in the link text. Feature-detect or live with the inconsistency.

9 javascript: Scheme — Deprecated & Dangerous

The javascript: URL scheme executes JS code in the location bar context. It was popular in the 1990s for one-liners like javascript:void(0) to make a link do nothing. It's now considered an anti-pattern and a security risk.

<!-- ❌ DON'T do this — outdated and insecure -->
<a href="javascript:void(0)" onclick="doSomething()">Click me</a>
<a href="javascript:alert('hi')">Say hi</a>

<!-- ✅ Use a button instead -->
<button type="button" onclick="doSomething()">Click me</button>

<-- ✅ Or an anchor that doesn't navigate, but still uses JS -->
<a href="#action" id="trigger" role="button">Click me</a>
<script>
  document.getElementById('trigger').addEventListener('click', e => {
    e.preventDefault();
    doSomething();
  });
</script>
Common Mistake javascript: URLs are blocked entirely in some contexts (e.g., pasted into the address bar of modern Chrome). They're also a vector for XSS attacks if the URL is built from user input. Avoid them in modern code.
Pro Tip — Anchor vs Button If clicking does navigation → <a href="...">. If clicking does an action (modal, fetch, toggle, submit) → <button>. This simple rule covers 95% of cases. Semantics matter for screen readers and keyboard users.

10 data: URLs

The data: scheme lets you embed small files directly in the URL itself. Useful for tiny images, generated text files, and one-off downloads.

<!-- Plain text file as a data URL -->
<a href="data:text/plain;charset=utf-8,Hello%20World" download="hello.txt">
  Download hello.txt
</a>

<-- Base64-encoded PNG -->
<a href="data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAAAEAAAABCAYAAAAfFcSJAAAA...">
  View tiny image
</a>

<-- Generated CSV download -->
<a href="data:text/csv;charset=utf-8,Name,Email%0Aalice,alice@x.com%0Abob,bob@x.com"
   download="contacts.csv">
  Download CSV
</a>
Common Mistake data: URLs are downloaded without restriction in Chrome, but in Firefox the top-level navigation to data: is blocked for security. Only use them with the download attribute, or for inline images — not for top-level page navigation.

11 Empty href

What happens with href=""? The browser treats it as a link to the current URL — clicking reloads the page (often without cache). This is almost never what you want.

<!-- ❌ Reloads the page on click -->
<a href="" onclick="doSomething()">Click</a>

<!-- ❌ Also bad — adds # to URL, may jump to top -->
<a href="#" onclick="doSomething()">Click</a>

<-- ✅ Use a button -->
<button onclick="doSomething()">Click</button>

<-- ✅ If you must use an anchor, prevent default navigation -->
<a href="#action" onclick="event.preventDefault(); doSomething()">Click</a>
Common Mistake — href="#" Jumps to Top Clicking href="#" navigates to the page's top (the empty fragment). If you have a long page and a button-shaped anchor with href="#", every click scrolls the user to the top. Always preventDefault() in the handler, or — better — use a <button>.

12 URL Encoding (Percent-Encoding)

URLs only allow a limited set of characters: alphanumerics, -, _, ., ~. Everything else must be percent-encoded as %XX where XX is the hex UTF-8 byte.

CharacterEncodedWhy
Space%20Spaces break URLs
&%26Separator in query strings
=%3DAssignment in query strings
?%3FStarts query string
#%23Starts fragment
/%2FPath separator
newline%0D%0ALine break in mailto body
+%2BOften means space in query strings
é, ü, 你%C3%A9, %C3%BC, %E4%BD%A0UTF-8 bytes, percent-encoded
 
<!-- ❌ Spaces break the URL -->
<a href="mailto:x@y.com?subject=Hello there">Bad</a>

<-- ✅ Encoded -->
<a href="mailto:x@y.com?subject=Hello%20there">Good</a>

<-- ✅ Best — let JS encode for you -->
<a id="email-link">Email</a>
<script>
  const url = `mailto:x@y.com?subject=${encodeURIComponent('Hello there')}&body=${encodeURIComponent('Line 1\nLine 2')}`;
  document.getElementById('email-link').href = url;
</script>
Pro Tip Use JavaScript's encodeURIComponent() for query values, encodeURI() for full URLs. They differ on which characters they encode. Or — better — use the URL and URLSearchParams APIs which handle encoding correctly.

15 Real-World Use Cases

Site Search

<a href="/search?q=shoes">Search "shoes"</a> — deep-link to a pre-filled search. Query string carries the term.

UTM Tracking

href="https://site.com?utm_source=newsletter&utm_medium=email&utm_campaign=fall" — analytics tracking without JavaScript.

Pre-filled Forms

href="/contact?subject=Billing&order=12345" — link from an order email that opens the contact form with context.

Calendar Links

Beyond mailto:, services like Google Calendar use deep URLs with query params to add events with one click.

Mobile Click-to-Call

Local business sites: phone number rendered as tel: link so mobile users tap to call. Critical for restaurants, clinics, plumbers.

WhatsApp / SMS Deep Links

https://wa.me/18005551234?text=Hello opens WhatsApp with a pre-filled message — a customer support shortcut.

"Back to Top" Links

<a href="#top">Back to top</a> paired with <html id="top"> — instantly scroll to top, no JS.

Permalink Anchors

Each section heading has an id; hovering reveals a # link. Clicking copies the URL with the fragment for sharing.

16 Summary

  • href is the only attribute that makes an <a> a real hyperlink.
  • URL structure: scheme://userinfo@host:port/path?query#fragment.
  • Absolute URLs include scheme + host; relative URLs resolve against current page.
  • Fragments (#id) never reach the server — they're handled client-side.
  • mailto:, tel:, sms: open native apps; tel: should always be in E.164 format.
  • javascript: URLs are deprecated and insecure — use buttons instead.
  • Empty href reloads the page; href="#" jumps to top — both bad for actions.
  • Always URL-encode special characters in query values: %20 for space, %26 for &, etc.
