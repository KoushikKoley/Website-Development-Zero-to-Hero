Section 3.1 · Anchor Tag

Anchor Tag Anatomy <a>

The <a> element is the connective tissue of the web. Every hyperlink — every "click here", every navigation menu item, every download button — flows from this single element. Master its attributes and you control how users move through content.

1 What Is an Anchor?

The <a> element (short for "anchor") creates hyperlinks — clickable connections between resources. The destination is set by the href attribute; the content between the opening and closing tags becomes the visible, clickable label.

Anchors are deceptively simple. A bare <a href="page.html">Go</a> works fine, but the element supports a dozen attributes that govern security, behavior, accessibility, and SEO. Understanding each one turns a "good enough" link into a robust, production-ready one.

Pro Tip The <a> element is the only HTML element that can natively navigate to a new URL without JavaScript. Even with frameworks like React or Vue, plain anchors remain the most reliable, accessible, and SEO-friendly way to link.

2 Anatomy Diagram

Below is the complete anatomy of an anchor tag with every common attribute illustrated:

<a href="https://example.com/report.pdf" target="_blank" rel="noopener noreferrer" download="annual-report-2024.pdf" hreflang="en" type="application/pdf" referrerpolicy="no-referrer"> Download Annual Report (PDF, 2.4 MB) </a> // href = destination URL (the only required attribute for navigation) // target = where to open it (_blank = new tab) // rel = relationship tokens (security + SEO hints) // download = suggest saving instead of navigating // hreflang = language of the destination // type = MIME type hint for the destination // referrerpolicy = how much referrer info to send

3 All Attributes at a Glance

The <a> element accepts these specific attributes (in addition to all global attributes like id, class, title, lang, style, and ARIA):

AttributePurposeRequired?Example
hrefThe destination URLYes (for navigation)href="/about"
targetBrowsing context: where to openNotarget="_blank"
relRelationship tokens, space-separatedNo (recommended)rel="noopener noreferrer"
downloadSuggest download instead of navigationNodownload="file.pdf"

Common Mistake Without href, an <a> is no longer a link — it becomes a placeholder. It will not be focusable, clickable, or announced as a link by screen readers. If you want a disabled look, use class="disabled" + aria-disabled="true", not a missing href.

4 href — The Destination

The href (Hypertext REFerence) attribute is the single most important attribute on an anchor. Without it, the element is rendered as static text. The value can be:

  • An absolute URL: https://example.com/page
  • A relative URL: about.html, ./about.html, ../about.html, /about
  • A fragment: #section-id
  • A special scheme: mailto:, tel:, sms:
  • An empty string: href="" (refers to the current page — usually a mistake)
<!-- Absolute -->
<a href="https://developer.mozilla.org/">MDN Web Docs</a>

<!-- Relative (same directory) -->
<a href="about.html">About Us</a>

<!-- Relative (root-absolute) -->
<a href="/contact">Contact</a>

<!-- Fragment (jump to #id on this page) -->
<a href="#table-of-contents">Jump to TOC</a>

<!-- Email -->
<a href="mailto:hello@example.com">Email us</a>

<!-- Telephone -->
<a href="tel:+18005551234">Call (800) 555-1234</a>
Pro Tip The full href deep dive is in the next file (href-attribute.html) — covering URL structure, encoding, fragment navigation, and pitfalls of javascript: URLs.

5 target — Where to Open

The target attribute tells the browser which browsing context (tab, window, or iframe) should display the destination. Five values exist:

ValueBehaviorUse Case
_selfDefault. Opens in the same tab/frame.Standard navigation.
_blankOpens in a new tab or window.External links, PDFs, "open in new tab" UX.
_parentOpens in the parent frame.iframe-based apps.
_topOpens in the topmost window (breaks out of all frames).Frame-busting, anti-clickjacking.
framenameOpens in the named iframe/window.Targeting a specific iframe by name.
 
<!-- Opens in same tab (explicit) -->
<a href="/about" target="_self">About</a>

<!-- Opens in new tab — ALWAYS pair with rel="noopener" -->
<a href="https://example.com" target="_blank" rel="noopener noreferrer">
  Visit Example
</a>

<!-- Opens in an iframe named "viewer" -->
<a href="doc.html" target="viewer">Open in viewer</a>
<iframe name="viewer" src="about:blank"></iframe>
Common Mistake — Security Hole Always use rel="noopener noreferrer" when setting target="_blank". Without it, the new page can access window.opener and redirect your tab to a phishing page. Modern browsers default to this for cross-origin links, but always be explicit.

6 rel — Relationship Tokens

The rel attribute is a space-separated list of tokens describing the relationship between the current page and the destination. The most common values:

TokenMeaningWhy It Matters
noopenerOpens without granting access to window.openerSecurity: prevents reverse-tabnabbing.
noreferrerDon't send the Referer headerPrivacy; also implies noopener.
nofollowTell search engines not to follow this linkSEO: paid links, untrusted content.
noopenerSecurity for new tabs—
externalLinks to an external siteUX hint, often styled with an icon.
next / prevPagination hintsSEO: paginated series.
authorLink to author pageSchema.org rich results.
licenseLink to license (CC, MIT, etc.)Legal context.
helpHelp documentationAccessibility hint.
tagTag/keyword linkBlog tag clouds.
bookmarkPermanent URL for nearest ancestorBlog post permalinks.
searchSearch endpointOften used with OpenSearch.
alternateAlternative version (RSS, translation)RSS feed discovery.
 
<!-- Standard safe external link -->
<a href="https://external.com" target="_blank" rel="noopener noreferrer external">
  External site
</a>

<!-- Paid/sponsored link for SEO -->
<a href="https://sponsor.com" rel="sponsored nofollow">Sponsored</a>

<!-- UGC like comments -->
<a href="https://spammy-link.com" rel="ugc">User-submitted</a>

<!-- Pagination -->
<a href="/page/2" rel="next">Next →</a>
<a href="/page/1" rel="prev">← Previous</a>
Pro Tip rel="ugc" (User Generated Content) and rel="sponsored" were introduced by Google in 2019 to replace the over-broad nofollow for paid/UGC contexts. Use the most specific token.

7 download — Force a Save

The download attribute tells the browser to download the linked resource instead of navigating to it. You can optionally suggest a filename.

<!-- Download with original filename -->
<a href="/files/report.pdf" download>Download report</a>

<!-- Download with a custom filename -->
<a href="/files/2024-q3-financials.pdf" download="Q3-2024-Financials.pdf">
  Download Q3 Financials
</a>

<!-- Generate a CSV on the fly with blob URL -->
<a href="data:text/plain;charset=utf-8,Hello%20World" download="hello.txt">
  Download hello.txt
</a>
Common Mistake — Cross-origin Limitation The download attribute is ignored if the URL is cross-origin (different scheme, host, or port) unless the server sends a Content-Disposition: attachment header. To force a download of a third-party file, proxy it through your own server.

The download attribute is covered in full depth in 04-Download-Links/download-attribute.html.

8 hreflang & type — Resource Hints

These two attributes are hints — they don't change behavior, but they help browsers, search engines, and assistive tech understand the destination.

hreflang — Language of the Destination

Uses an IETF language tag like en, en-US, fr-CA, zh-Hans. Most useful for localized alternative versions of the same page (paired with rel="alternate").

<!-- English version -->
<a href="/en/about" hreflang="en" rel="alternate">About</a>

<!-- French version of the same page -->
<a href="/fr/a-propos" hreflang="fr" rel="alternate">À propos</a>

<!-- Simplified Chinese version -->
<a href="/zh-Hans/about" hreflang="zh-Hans" rel="alternate">关于</a>

type — MIME Type Hint

Indicates the MIME type of the linked resource, e.g. application/pdf, image/png, text/csv. Browsers use it as a hint, not a guarantee.

<a href="/files/budget.csv" type="text/csv" download>Download budget (CSV)</a>
<a href="/files/manual.pdf" type="application/pdf">View manual (PDF)</a>
<a href="/feeds/rss.xml" type="application/rss+xml" rel="alternate">RSS feed</a>
Pro Tip Both hreflang and type are most powerful in <link rel="alternate"> tags in the <head> for SEO and feed discovery. On <a> elements they're rarely displayed to users but can be read by extensions and crawlers.

9 referrerpolicy — Control the Referer Header

When you click a link, the browser normally sends a Referer HTTP header telling the destination site which page you came from. referrerpolicy lets you control this per-link.

ValueSends Referer?When
no-referrerNeverMaximum privacy
no-referrer-when-downgradeOnly same-security (HTTPS→HTTPS)Default in many browsers
same-originOnly to same siteInternal analytics
originSends only the origin (no path)Privacy + analytics
strict-originOrigin only, HTTPS→HTTPSModern default
origin-when-cross-originFull URL same-origin; origin only cross-originBalanced
strict-origin-when-cross-originStrict origin when crossing originsBrowser default since 2020
unsafe-urlAlways sends full URLAvoid — leaks paths
 
<!-- Don't leak that the user came from your admin panel -->
<a href="https://analytics-vendor.com" referrerpolicy="no-referrer">
  Open dashboard
</a>

<!-- Same-origin only — useful for internal navigation -->
<a href="/admin" referrerpolicy="same-origin">Admin</a>
Common Mistake Default policy in Chrome, Firefox, and Edge is now strict-origin-when-cross-origin. This means cross-origin destinations see only your origin (e.g. https://yoursite.com), not the full path. If a partner relies on full referrer URLs, set referrerpolicy="unsafe-url" explicitly — and ask why.

10 Text, Image, and Block Links

The content inside an <a> can be plain text, an image, structured inline content, or — since HTML5 — even block-level elements like headings, paragraphs, and lists.

1. Text Links

The simplest and most common form. The visible text is called the anchor text and is what screen readers announce and search engines index.

<a href="/products">Browse our products</a>
Browse our products

2. Image Links

Wrap an <img> in an <a>. The image's alt text becomes the link's accessible name.

<a href="/home">
  <img src="logo.svg" alt="Acme Corp home" width="120" height="40">
</a>

<!-- Icon link with text alongside -->
<a href="/cart" class="cart-link">
  <svg width="20" height="20" aria-hidden="true">...</svg>
  <span>Cart (3)</span>
</a>
Cart (3)

3. Block Links (Card Pattern)

Since HTML5, anchors can wrap "transparent" flow content — including headings, paragraphs, and images. This is perfect for clickable cards.

<a href="/blog/post-1" class="card-link">
  <article>
    <h3>Understanding CSS Grid</h3>
    <p>A deep dive into the two-dimensional layout system...</p>
    <time datetime="2024-09-15">Sep 15, 2024</time>
  </article>
</a>

Common Mistake — Nested Interactive Elements You cannot nest a <button>, another <a>, or <input> inside an <a>. The HTML spec forbids it; browsers will silently split your anchor. If you need a button inside a clickable card, use JavaScript to handle the click, or restructure with absolute-positioned overlays.

11 Default Styling

Browsers apply sensible defaults to anchors, but they vary subtly across vendors. Here's what you inherit before writing any CSS:

StateDefault ColorDefault Decoration
Unvisited (:link)#0000EE (blue)Underline
Visited (:visited)#551A8B (purple)Underline
Hover (:hover)InheritsUnderline (often color change)
Active (:active)#FF0000 (red) in some browsersUnderline
Focus (:focus)Outline ringUnderline

Modern CSS resets (Normalize, Modern CSS Reset, Tailwind Preflight) usually override these to use the page's text color and remove underlines, expecting you to re-add them deliberately. Always re-add underline — it's the universal affordance for "this is clickable".

/* Modern baseline — colors the page's text color, underline on hover only */
a {
  color: currentColor;
  text-decoration: none;
  transition: color 0.15s;
}
a:hover { color: var(--brand); text-decoration: underline; }

12 The Five Link States (LVHA)

Links have five pseudo-class states. Memorize the order — LVHA (Link, Visited, Hover, Active) — because CSS specificity means later rules win when states overlap:

a:link    { color: #2563eb; }  /* Unvisited */
a:visited { color: #6b21a8; }  /* Visited */
a:hover   { color: #dc2626; }  /* Mouse over */
a:active  { color: #f59e0b; }  /* Being clicked */
a:focus   { outline: 3px solid #2563eb; outline-offset: 2px; }
Unvisited Hover me Click me Tab to me
Common Mistake — Wrong Order If you write :hover before :visited, the hover style won't apply to visited links because :visited will override it. Always order: :link, :visited, :hover, :active, :focus.
Pro Tip For privacy reasons, browsers severely restrict what you can style on :visited links. You can change color, background-color, border-color, outline-color, column-rule-color, and text-decoration-color — but not font-size, display, padding, or anything that affects layout. This prevents history-sniffing attacks.

13 Focus Styles — Don't Remove Them

Keyboard users (and many power users) navigate by Tab. The focus ring is how they know which link is "active". Removing it with outline: none is one of the most common accessibility failures on the web.

/* ❌ NEVER do this */
a { outline: none; }

/* ✅ Always do this — visible focus, only when keyboard-navigating */
a:focus-visible {
  outline: 3px solid var(--brand);
  outline-offset: 3px;
  border-radius: 2px;
}

/* Optional: also style for mouse focus, but typically you want
   the ring only for keyboard users. Use :focus-visible, not :focus. */
Pro Tip :focus-visible is supported in all modern browsers since 2022. It applies the focus ring only when the browser heuristically decides the user is keyboard-navigating — meaning mouse users don't see an ugly ring after a click, but keyboard users still get one. Use it over plain :focus.

14 Try It Yourself

Exercise 1 — Anatomy Labeling Write a single anchor tag that uses all seven attributes covered in section 3 (href, target, rel, download, hreflang, type, referrerpolicy). Point it to a PDF on a fictional domain. Add a comment explaining each attribute.
Exercise 2 — Image Link Create an anchor that wraps an SVG icon (any icon — a magnifying glass for search). Make the link point to /search and ensure the SVG has appropriate aria-hidden or a visible text label.
Exercise 3 — Block Card Build a clickable article card using the block-link pattern. Include a heading, a paragraph of teaser text, and a date. Verify it works with keyboard navigation (Tab to focus, Enter to "click").
Exercise 4 — LVHA Practice Style a link with all five pseudo-classes. Choose distinct colors for each. Then test by visiting the link (you may need to clear history to test :link vs :visited).
Exercise 5 — Focus Ring Customization Replace the default focus outline with a custom 3px solid ring using :focus-visible. Test by Tab-navigating through a list of links. Make sure the ring is visible against both light and dark backgrounds.

15 Common Mistakes

MistakeWhy It's WrongFix
Missing hrefLink becomes inert placeholder; not focusable or announced.Always set href, even if #. For disabled state use aria-disabled="true".
target="_blank" without rel="noopener"Security: reverse tabnabbing attack.Always add rel="noopener noreferrer".
Removing focus outlineKeyboard users can't see where they are.Style :focus-visible; never outline: none.
Link text "click here"Bad for SEO, screen readers, and skim-readers.Use descriptive text: "Download the Q3 report".
Nesting interactive elementsInvalid HTML; browsers split the anchor.Restructure with overlays or JS click handlers.
Using javascript:void(0) in hrefDoesn't work without JS; copies badly; bad for accessibility.Use <button> instead — that's what they're for.

16 Real-World Use Cases

Navigation Menus

Every nav item is an <a>. Pair with <nav>, <ul>, aria-current="page" for accessible site navigation.

Breadcrumbs

Sequential anchors separated by separators (›). Use <nav aria-label="Breadcrumb"> with an ordered list.

Read More / CTA

Stylized anchors styled as buttons. Use <a> only when navigating; otherwise use <button>.

Pagination

Sequential page links with rel="prev"/rel="next". Wrap in <nav aria-label="Pagination">.

Article Cards

Block links wrapping entire card content. Most modern blog designs (Medium, Substack) use this pattern.

Email / Phone CTAs

mailto: and tel: schemes make contact info tappable on mobile — critical for local business sites.

Download Buttons

PDFs, CSVs, images, generated files. Pair with download attribute and proper MIME type.

Skip Links

The first focusable element on a page: <a href="#main">Skip to content</a>. Vital for keyboard users.

Social / External

Outbound links always get target="_blank" + rel="noopener noreferrer external". Often styled with external-link icon.

17 Summary

  • The <a> element creates hyperlinks; href is its only required attribute for navigation.
  • Seven attributes define behavior: href, target, rel, download, hreflang, type, referrerpolicy.
  • Always pair target="_blank" with rel="noopener noreferrer" — security-critical.
  • Content can be text, images, or block elements — but never nest interactive elements.
  • Five link states follow LVHA order: :link, :visited, :hover, :active, :focus.
  • Always style :focus-visible; never remove the focus ring.
  • Visited-link styling is restricted for privacy (history-sniffing protection).
  • For non-navigation actions (form submit, modal open), use <button>, not <a href="#">.
