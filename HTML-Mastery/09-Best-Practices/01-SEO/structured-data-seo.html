Structured Data & Rich Results

1 What is Structured Data?

Structured data is a machine-readable description of your page's content, written in a vocabulary called Schema.org and embedded in the HTML. Search engines use it to display rich results — visual enhancements like star ratings, event dates, recipe cook times, FAQ accordions, and breadcrumb trails.

Without structured data, Google reads your page as a stream of words. With it, Google knows "this is a recipe for sourdough bread, takes 4 hours, has 12 ingredients, has 4.7 stars from 230 reviews".

Pro Tip Structured data doesn't directly boost rankings, but it dramatically increases click-through rate (CTR) by making your result more visually prominent. Higher CTR is a ranking signal. The indirect effect is substantial.

2 JSON-LD vs Microdata vs RDFa

Three formats exist for embedding structured data. Google strongly recommends JSON-LD — it's the only one they actively document, and the only format new features are tested against.

JSON-LD ✓ Recommended

A <script type="application/ld+json"> block in the head. Separates data from markup, easiest to maintain, easiest to test.

Microdata

Attributes like itemscope, itemtype, itemprop sprinkled through HTML. Couples data to markup. Discouraged.

RDFa

Similar to Microdata but uses vocab and property attributes. Rarely used for SEO. Discouraged.

<!-- JSON-LD: clean, separate from HTML -->
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Article",
  "headline": "Sourdough Hydration Guide",
  "author": { "@type": "Person", "name": "Jane Dough" }
}
</script>

<!-- Microdata: attributes polluting the HTML -->
<article itemscope itemtype="https://schema.org/Article">
  <h1 itemprop="headline">Sourdough Hydration Guide</h1>
  <span itemprop="author" itemscope itemtype="https://schema.org/Person">
    <span itemprop="name">Jane Dough</span>
  </span>
</article>

3 Article Schema

For news articles, blog posts, and editorial content. Eligible for "Top stories" carousel and rich title treatment.

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Article",
  "headline": "Sourdough Hydration: A Complete Guide from 60% to 85%",
  "description": "Understand sourdough hydration ratios from 60% to 85%.",
  "image": "https://example.com/img/sourdough-1200x800.jpg",
  "datePublished": "2024-03-14T08:00:00+00:00",
  "dateModified": "2024-09-02T10:30:00+00:00",
  "author": {
    "@type": "Person",
    "name": "Jane Dough",
    "url": "https://example.com/authors/jane"
  },
  "publisher": {
    "@type": "Organization",
    "name": "BakeLab",
    "logo": {
      "@type": "ImageObject",
      "url": "https://example.com/logo.png",
      "width": 512,
      "height": 512
    }
  },
  "mainEntityOfPage": {
    "@type": "WebPage",
    "@id": "https://example.com/guides/hydration"
  }
}
</script>
Common Mistake Image too small. Google requires images at least 1200px wide and encoded as JPG, PNG, or WebP. A 400px square thumbnail will disqualify you from Top stories.

4 Product Schema

For e-commerce product pages. Eligible for price snippets, availability, and review star ratings in search results.

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Product",
  "name": "Whisper-Q Wireless Headphones",
  "image": [
    "https://example.com/img/headphones-1x1.jpg",
    "https://example.com/img/headphones-4x3.jpg",
    "https://example.com/img/headphones-16x9.jpg"
  ],
  "description": "Over-ear wireless headphones with active noise cancellation.",
  "sku": "WQ-2024-BLK",
  "mpn": "ACME-12345",
  "brand": { "@type": "Brand", "name": "Acme" },
  "offers": {
    "@type": "Offer",
    "url": "https://example.com/products/whisper-q",
    "priceCurrency": "USD",
    "price": "249.00",
    "availability": "https://schema.org/InStock",
    "priceValidUntil": "2025-12-31",
    "itemCondition": "https://schema.org/NewCondition"
  },
  "aggregateRating": {
    "@type": "AggregateRating",
    "ratingValue": "4.7",
    "reviewCount": "230"
  }
}
</script>

Required fields

FieldRequired?Notes
nameRequiredProduct name
imageRequired≥ 1200px, multiple aspect ratios recommended
offers.priceRequired for price snippetNumber, not string
offers.priceCurrencyRequiredISO 4217: USD, EUR
offers.availabilityRequiredInStock, OutOfStock, etc.
aggregateRatingOptional but recommendedRequired for star ratings

5 BreadcrumbList

Displays breadcrumb trails in search results (e.g., Home › Electronics › Headphones › Whisper-Q). Improves UX and signals site hierarchy.

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "BreadcrumbList",
  "itemListElement": [
    {
      "@type": "ListItem",
      "position": 1,
      "name": "Home",
      "item": "https://example.com/"
    },
    {
      "@type": "ListItem",
      "position": 2,
      "name": "Electronics",
      "item": "https://example.com/electronics"
    },
    {
      "@type": "ListItem",
      "position": 3,
      "name": "Headphones",
      "item": "https://example.com/electronics/headphones"
    },
    {
      "@type": "ListItem",
      "position": 4,
      "name": "Whisper-Q Wireless Headphones",
      "item": "https://example.com/electronics/headphones/whisper-q"
    }
  ]
}
</script>
Pro Tip The position field is 1-indexed (starts at 1, not 0). Mismatching the breadcrumb visible on the page (which usually hides "Home") is a common cause of warnings.

6 FAQPage

Displays an accordion of questions and answers directly in search results. Excellent for capturing traffic from question-based queries.

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "What is the ideal sourdough hydration for beginners?",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "For beginners, 70% hydration offers the best balance between workability and crumb openness. Doughs at 70% are tacky but not unmanageable, and they tolerate fermentation timing errors well."
      }
    },
    {
      "@type": "Question",
      "name": "Can I use cold water for my sourdough starter?",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "Cold water slows fermentation but won't kill your starter. Use water between 75°F and 85°F (24–29°C) for optimal yeast activity. Avoid chlorinated tap water."
      }
    }
  ]
}
</script>

12 Common Mistakes

✗ Disqualifying errors

  • Markup mismatches visible content (FAQ schema for content that isn't a real FAQ on the page)
  • Missing required fields (e.g., Product without offers)
  • Image under 1200px wide
  • Dates in wrong format (use ISO 8601: 2024-09-02T10:30:00+00:00)
  • Prices as strings with currency symbols ("$249.00")
  • Property names in camelCase wrong (aggregateRating not aggregate_rating)
  • Multiple conflicting schemas on the same page

✓ Best practices

  • Markup must describe content that's actually visible on the page
  • Include all required fields for the schema type
  • Use multiple image URLs with different aspect ratios
  • ISO 8601 dates with timezone offsets
  • Numbers as raw numbers, currency in priceCurrency
  • Copy exact property names from Schema.org
  • One primary entity per page; use @graph for multiple
Common Mistake Adding FAQ schema to a page that doesn't visibly show FAQs. Google manual reviewers and algorithmic checks compare the structured data to the rendered DOM. Mismatches lead to manual actions and loss of all rich results across the site.

13 Exercise

Exercise: Build Structured Data for a Recipe Blog

You're publishing a recipe page titled "Tahini Chocolate Chip Cookies". The page contains:

  • Recipe: 12 ingredients, 6 steps, 25 min prep + 12 min bake
  • 4.6 stars from 87 reviews
  • Breadcrumb: Home › Recipes › Cookies › Tahini Chocolate Chip
  • FAQ: "Can I substitute sunflower seed butter?", "Are these vegan?"

Tasks:

  1. Write a Recipe JSON-LD block with all required fields.
  2. Add a BreadcrumbList block.
  3. Add a FAQPage block for the two questions.
  4. Combine all three into a single <script type="application/ld+json"> using a @graph array.
  5. Run the result through the Rich Results Test and fix any errors.

14 Crawler Support

Google: full JSON-LD support, all documented features Bing: supports JSON-LD for most types Yandex: supports JSON-LD DuckDuckGo: parses for recipe & product enrichment All modern browsers: render the script block silently

JSON-LD is invisible to users — the script tag's contents are not rendered. Search engines parse it server-side or during the second-wave render. There is zero performance penalty for including structured data.

Real-World Use Case A recipe blog added structured data (Recipe, BreadcrumbList, FAQPage) to its top 50 recipes. Within 60 days, 38 of those recipes appeared with rich results, and organic traffic to those pages increased 64%. The FAQ accordions alone captured an estimated 12% of long-tail question searches.
