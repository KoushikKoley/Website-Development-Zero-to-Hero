<blockquote> vs <figure>

Both elements wrap content with semantic meaning — but for different reasons. Knowing when each is appropriate, and how they combine, is a small detail that separates good HTML from great HTML.

2 Semantic Differences

A <blockquote> says "this text came from somewhere else". A <figure> says "this content is a self-contained unit that could be lifted out of the article". The two are orthogonal — a blockquote can be a figure, and a figure can contain a blockquote.

Blockquote is about source

Its purpose is to attribute text. It belongs in the flow of paragraphs wherever the quoted passage belongs.

Figure is about structure

Its purpose is to mark self-contained units. It can hold any media type — including a blockquote.

3 When to Use <blockquote> Alone

When the quote is part of the prose flow — your sentence introduces it ("The author wrote:") and continues after. The quote isn't a "figure" — it's just attribution.

<p>As Tim Berners-Lee wrote in his 1989 proposal:</p>

<blockquote cite="https://w3.org/History.html">
  <p>This proposal concerns the management of general information
  about accelerators and experiments at CERN.</p>
</blockquote>

<p>The rest of the document elaborates on that vision.</p>

As Tim Berners-Lee wrote in his 1989 proposal:

This proposal concerns the management of general information about accelerators and experiments at CERN.

The rest of the document elaborates on that vision.

Note: no <figcaption>, no role="figure" — just a plain blockquote with a cite URL.

4 When to Use <figure> Alone

When the content is self-contained and benefits from a visible label ("Figure 1") — a chart, photo, code listing, or a pull-quote treated as a graphic element.

<figure>
  <img src="chart-q3.png" alt="Q3 revenue rose 42%">
  <figcaption><strong>Figure 1.</strong> Q3 revenue by week.</figcaption>
</figure>

No quote, no attribution — pure structural captioning.

5 Blockquote Inside Figure (the Best Combo)

When a pull-quote or testimonial deserves a visible caption (author, source, role), wrap the <blockquote> in a <figure> and use <figcaption> for attribution.

<figure>
  <blockquote>
    <p>The best way to predict the future is to invent it.</p>
  </blockquote>
  <figcaption>
    — Alan Kay, <cite>Personal Dynamic Media</cite>, 1977
  </figcaption>
</figure>
Why this is the right pattern <blockquote> handles the quote semantics + cite URL; <figure> makes the whole thing self-contained and labelable; <figcaption> displays the attribution visibly. Each element plays its role.

6 Can a Figure Be a Pull-Quote?

Yes — and it's the recommended pattern. A pull-quote repeats text from the article in a visually prominent way. As a <figure>, it's structurally separate; with aria-hidden="true", screen readers skip it (so they don't hear the same text twice).

<!-- Inside the article body -->
<p>The new framework ships with zero runtime dependencies,
making it suitable for embedded and IoT contexts where
binary size matters.</p>

<figure aria-hidden="true">
  <blockquote>
    <p>Zero runtime dependencies — ideal for IoT.</p>
  </blockquote>
</figure>

<p>The team achieved this by compiling templates at
build time rather than interpreting them at runtime.</p>
Common mistake Forgetting aria-hidden="true" on a pull-quote that duplicates article text. Screen readers will read the same sentence twice — once in the paragraph, once in the pull-quote.
Pro tip If the pull-quote paraphrases rather than duplicates the text, skip aria-hidden — the screen-reader version is meaningfully different.

7 Decision Tree

Is it a quotation?
├─ Yes → Is it part of the prose flow (your sentence introduces it)?
│    ├─ Yes → Use <blockquote> alone (with cite URL).
│    └─ No → Use <figure> containing <blockquote>, with <figcaption> for attribution.
│            └─ Duplicates article text? Add aria-hidden="true".
└─ No → Is the content self-contained, captioned, referenced?
      ├─ Yes → Use <figure> with <figcaption>.
      └─ No → Use a plain <div> or <section>; don't fake semantics.

8 Citation Patterns Inside Each Element

Both elements can hold citations, but the way they hold them differs. Here's a quick guide.

Inside <blockquote>

Use the cite attribute for the source URL (invisible but machine-readable), and an inline <cite> element for the visible work title. Author name goes in plain text or a <span>.

<blockquote cite="https://example.com/article">
  <p>The quote text.</p>
  <footer>
    — <span>Jane Doe</span>,
    <cite>The Big Book of Web Standards</cite>, 2024
  </footer>
</blockquote>

Inside <figure> with <figcaption>

The cite attribute is meaningless on <figure> — instead, put the entire attribution inside the <figcaption>. Use <a href> for the link and <cite> for the work title.

<figure>
  <blockquote cite="https://example.com/article">
    <p>The quote text.</p>
  </blockquote>
  <figcaption>
    — <span>Jane Doe</span>,
    <cite><a href="https://example.com/article">The Big Book of Web Standards</a></cite>, 2024
  </figcaption>
</figure>
Pro tip When in doubt, include both the cite attribute on the <blockquote> (for machine readers like search engines) and a visible <a href> inside the <figcaption> (for human readers). They serve different audiences.

10 Try It Yourself

Exercise 1 — Inline quote Write a paragraph that introduces a quote, contains the <blockquote>, then continues. Add a cite URL on the blockquote. No <figure> needed.
Exercise 2 — Captioned testimonial Build a testimonial card: <figure> → <blockquote> → <p> (quote text) + <figcaption> ("— Jane Doe, CEO of Acme"). Style as a card with colored border.
Exercise 3 — Pull-quote in article Write a 3-paragraph article. Insert a pull-quote between paragraphs 2 and 3 that repeats a sentence from paragraph 2. Mark it aria-hidden="true". Verify with a screen reader that the pull-quote is skipped.
Exercise 4 — Decision tree practice Write down 5 different "quote-like" scenarios (testimonial, book excerpt, internal pull-quote, paraphrase, inline quote). For each, decide: blockquote alone? figure + blockquote? figure alone? q? Document your reasoning.

11 Summary

  • <blockquote> = quotation from another source; about attribution.
  • <figure> = self-contained content with optional caption; about structure.
  • Use <blockquote> alone when the quote flows in the prose.
  • Use <figure> containing <blockquote> when you want a visible caption (attribution, role).
  • Pull-quotes that duplicate article text need aria-hidden="true".
  • <cite> for work titles only, never for author names.
  • Never use <blockquote> just for visual indentation.
