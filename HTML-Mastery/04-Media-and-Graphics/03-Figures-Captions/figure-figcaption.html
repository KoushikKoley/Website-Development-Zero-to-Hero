<figure> & <figcaption> — A Deep Dive

The figure element groups any self-contained content with an optional caption. It works for images, code listings, blockquotes, tables, videos, and more — making it one of the most versatile semantic elements in HTML.

1 The Semantics of <figure>

Per the HTML spec, <figure> represents self-contained content, possibly with a caption, that is typically referenced from the main flow of the document as a single unit. It can be moved away from the main text without losing its meaning.

Three properties define a figure:

  • Self-contained — it makes sense on its own.
  • Optionally captioned — the <figcaption> child provides a label.
  • Positionally independent — moving it to a sidebar or appendix doesn't break the document.
What counts as "self-contained"? A photograph with caption, a chart, a code listing, a pull-quote, an equation, a video clip, a data table that supplements the text. Not: a hero image that is the page content, an inline icon, a decorative background.

2 Figure with Images

The most common use — a captioned photo or illustration.

<figure>
  <img src="everest.jpg"
       alt="Mount Everest summit at sunrise"
       width="1600" height="1067" loading="lazy">
  <figcaption>
    <strong>Figure 1.</strong> The summit of Mount Everest
    at sunrise, photographed May 2024.
  </figcaption>
</figure>
Pro tip Don't repeat the alt text verbatim in the caption. Alt is for screen readers (describes the image); the caption is for sighted users (provides context). Two audiences, two purposes.

3 Code Listings as Figures

Technical writing benefits greatly from captioned code listings. Place the caption above so the reader sees the title before reading the code.

<figure>
  <figcaption><strong>Listing 1.</strong> A minimal HTTP server in Node.js.</figcaption>
  <pre><code class="language-js">const http = require('http');
http.createServer((req, res) => {
  res.writeHead(200, { 'Content-Type': 'text/plain' });
  res.end('Hello, world!');
}).listen(3000);</code></pre>
</figure>

4 Blockquotes Inside Figures

A pull-quote — a highlighted excerpt from the article — fits perfectly in a <figure> with the source as the caption.

<figure>
  <blockquote>
    <p>The web is the most powerful, universal platform
    humans have ever built. Don't waste it.</p>
  </blockquote>
  <figcaption>
    — <cite>Tim Berners-Lee</cite>, WWW Foundation, 2023
  </figcaption>
</figure>
Pro tip Use <cite> for the source's work title (book, talk, etc.), not the author name. For author, a plain span or "— " prefix is fine.

5 Tables in Figures

When a table is supplementary (e.g. an appendix-style data table), wrap it in <figure> with a <figcaption> caption. The table itself keeps its own <caption> only if needed for screen-reader navigation.

<figure>
  <figcaption><strong>Table 1.</strong> Top 5 browsers by market share, Q4 2024.</figcaption>
  <table>
    <thead>
      <tr><th>Browser</th><th>Share</th></tr>
    </thead>
    <tbody>
      <tr><td>Chrome</td><td>65.4%</td></tr>
      <tr><td>Safari</td><td>18.7%</td></tr>
      <tr><td>Edge</td><td>5.4%</td></tr>
      <tr><td>Firefox</td><td>2.9%</td></tr>
      <tr><td>Samsung</td><td>2.5%</td></tr>
    </tbody>
  </table>
</figure>

6 Videos & Audio in Figures

A short video clip or audio player that supplements the article is a great figure candidate. The caption can describe what to watch for.

<figure>
  <video controls poster="clip-poster.jpg" width="640" height="360">
    <source src="clip.mp4" type="video/mp4">
    <source src="clip.webm" type="video/webm">
    <track kind="captions" src="clip.vtt" srclang="en" default>
  </video>
  <figcaption>
    <strong>Video 1.</strong> A 30-second demonstration of the
    new feature. Captions available via the CC button.
  </figcaption>
</figure>

7 Positioning the Caption

<figcaption> can be the first or last child. Convention:

Content typeCaption positionWhy
Image, photo, chartBelow (last child)Readers see image first, then context
Code listingAbove (first child)Title primes the reader before code
BlockquoteBelowAttribution after the quote
TableAbove (or use table's own caption)Title primes before scanning rows
VideoBelowDon't crowd the player

Overlay caption

figure { position: relative; display: inline-block; }
figure img { display: block; max-width: 100%; }
figure figcaption {
  position: absolute; bottom: 0; left: 0; right: 0;
  background: rgba(0,0,0,0.6); color: #fff;
  padding: 10px 14px; margin: 0;
  font-size: 0.9rem;
}

Side caption (magazine style)

figure { display: grid; grid-template-columns: 2fr 1fr; gap: 16px; }
figure img { grid-column: 1; }
figure figcaption { grid-column: 2; align-self: center; }

8 Accessibility with aria-labelledby

By default, screen readers announce the figure and its caption. To make the relationship explicit and ensure the caption is announced as the figure's label, use aria-labelledby.

<figure aria-labelledby="fig1-caption">
  <img src="chart.png"
       alt="Bar chart: revenue rose 42% from $1.2M to $1.7M in Q3"
       width="800" height="500">
  <figcaption id="fig1-caption">
    <strong>Figure 1.</strong> Q3 revenue by week.
  </figcaption>
</figure>

With this in place, a screen reader announces something like: "Figure 1, Q3 revenue by week." before describing the image's alt text.

Common mistake Pointing aria-labelledby at the caption but then also using the caption text as the image's alt. Screen readers may announce the same text twice. Either use a brief alt + descriptive caption (different content), or set alt="" and rely entirely on aria-labelledby.
Pro tip — role="group" <figure> has an implicit ARIA role of figure. If you're using a generic container that needs the same semantics, add role="figure" and aria-labelledby manually.

9 Multiple Figcaptions — What's Allowed

Only one <figcaption> per <figure>. If you need multiple text labels (e.g. for each image in a group), use other elements inside the figure:

<figure>
  <img src="step-1.png" alt="Step 1: Mixing flour">
  <p><em>Step 1.</em> Mix flour and water.</p>
  <img src="step-2.png" alt="Step 2: Kneading dough">
  <p><em>Step 2.</em> Knead for 5 minutes.</p>
  <figcaption>
    <strong>Figure 2.</strong> Two steps in bread-making.
  </figcaption>
</figure>

The single <figcaption> labels the whole group; per-item labels are plain paragraphs.

10 Common Mistakes

MistakeWhy it's badFix
Two <figcaption> in one figureInvalid HTMLMerge into one or use <p> for inner labels
<figcaption> outside <figure>Orphan; spec violationAlways nest in figure
Wrapping every <img> in a figureImplies self-containment that doesn't existUse figure only for captioned/referenced content
Using <caption> inside <figure>That's for tables onlyUse <figcaption>
Repeating alt in <figcaption>Redundant for screen readersalt = what, caption = why/context
Forgetting id + aria-labelledbyCaption may not be announced as figure's labelPair them for explicit labeling
Long, rambling captionsIt's a label, not an articleKeep to 1-2 sentences; link out for more

11 Try It Yourself

Exercise 1 — Captioned chart Find a chart image. Wrap it in <figure> with alt describing what's shown and a <figcaption> describing the trend. Add id to the caption and aria-labelledby to the figure.
Exercise 2 — Code listing with title Write a 10-line code snippet in a <pre><code> block. Wrap in <figure> with <figcaption> above ("Listing 1: Reverse a string in Python."). Style the caption bold and blue.
Exercise 3 — Pull-quote with attribution Quote a famous line from a book. Wrap in <figure> → <blockquote> → <p> + <figcaption> with <cite> for the source work.
Exercise 4 — Overlay caption Take a landscape photo. Build a <figure> with an absolutely-positioned <figcaption> overlay at the bottom. Use a semi-transparent dark background for the caption text.

12 Summary

  • <figure> = self-contained content, optionally captioned, positionally independent.
  • Works for images, code listings, blockquotes, tables, videos, audio, equations.
  • <figcaption> = the one and only caption; can be first or last child.
  • Only one <figcaption> per figure — use <p> for inner labels.
  • Pair id on the caption with aria-labelledby on the figure for explicit labeling.
  • Caption = context for sighted users; alt = description for screen readers. Different audiences.
  • Use CSS counters to auto-number "Figure N" sequences.
