Inline SVG — Scalable, Scriptable, Stylable

SVG is XML for drawing. Inline it directly in HTML and you get crisp graphics at any size, full CSS styling, full JavaScript control, and accessibility for free. The best choice for icons, logos, and charts.

1 Why Inline SVG?

Scalable

Vector math, not pixels. One file looks crisp at 16px or 4000px. No more 1x/2x/3x exports.

Scriptable

Every element is a DOM node. Animate, transform, or react to clicks with vanilla JS.

CSS-stylable

Set fill, stroke, opacity from your stylesheet. Inherit colors via currentColor.

Accessible

Use <title> and <desc> for screen readers, role="img" and aria-label for context.

Tiny

An icon set in SVG is often smaller than one PNG. No HTTP request when inline.

Animatable

CSS animations, SMIL, or the Web Animations API. No images or videos to load.

2 Anatomy of an SVG

<svg xmlns="http://www.w3.org/2000/svg"
     width="100" height="100"
     viewBox="0 0 100 100"
     role="img" aria-labelledby="title desc">
  <title id="title">Blue circle</title>
  <desc id="desc">A solid blue circle filling the canvas.</desc>
  <circle cx="50" cy="50" r="45" fill="#2563eb" />
</svg>

Note: xmlns is technically required by the spec but browsers usually infer it for inline SVG in HTML5. Best practice is to include it.

3 viewBox & Sizing

viewBox="minX minY width height" defines the SVG's internal coordinate system. width/height (attributes or CSS) define how big it renders on screen.

<!-- 100×100 internal coords, renders at 200×200 (2x scaled) -->
<svg viewBox="0 0 100 100" width="200" height="200">
  <circle cx="50" cy="50" r="40" />
</svg>

Best practice: set viewBox always; let CSS control rendered size with width: 100% or fixed dimensions.

svg { width: 100%; height: auto; }
Pro tip — preserveAspectRatio Default "xMidYMid meet" keeps aspect ratio and centers. Set "none" to stretch (rarely wanted). Set "xMidYMid slice" to crop like CSS object-fit: cover.

4 Basic Shapes

<!-- Rectangle -->
<rect x="10" y="10" width="80" height="50" rx="8"
      fill="#2563eb" stroke="#1e3a8a" stroke-width="2" />

<!-- Circle -->
<circle cx="50" cy="50" r="30" fill="#7c3aed" />

<!-- Ellipse -->
<ellipse cx="50" cy="50" rx="40" ry="20" fill="#16a34a" />

<!-- Line -->
<line x1="10" y1="90" x2="90" y2="10"
      stroke="#dc2626" stroke-width="3" stroke-linecap="round" />

<!-- Polyline (open path) -->
<polyline points="10,90 30,40 60,60 90,10"
          fill="none" stroke="#f59e0b" stroke-width="3" />

<!-- Polygon (closed path) -->
<polygon points="50,10 90,40 70,90 30,90 10,40"
         fill="#ec4899" />

5 The <path> Element

The Swiss-army knife of SVG. Its d attribute is a series of commands: M (move), L (line), C (cubic Bézier), Q (quadratic), A (arc), Z (close).

<!-- Heart shape using cubic Béziers -->
<path d="M50,90
         C 20,60 20,30 35,25
         C 45,22 50,30 50,35
         C 50,30 55,22 65,25
         C 80,30 80,60 50,90 Z"
      fill="#dc2626" />
CommandMeaningExample
M x yMove (without drawing)M50,90
L x yLine toL100,100
H x / V yHorizontal / vertical lineH200 V100
C x1 y1, x2 y2, x yCubic Bézier (two control points)C 20,60 20,30 35,25
Q x1 y1, x yQuadratic Bézier (one control point)Q 50,0 50,50
A rx ry rot large-arc sweep x yArcA 25,25 0 0,1 50,25
ZClose pathZ
Pro tip Uppercase commands are absolute; lowercase are relative. M50,90 jumps to (50,90); m50,90 moves 50 right and 90 down from current position.

6 Grouping with <g>

<g> groups shapes so you can transform or style them as a unit. Attributes on the group inherit to children.

<g transform="translate(50,50) rotate(45)"
   fill="#2563eb" stroke="#1e3a8a" stroke-width="2">
  <rect x="-20" y="-20" width="40" height="40" />
  <circle cx="0" cy="0" r="10" fill="#fff" />
</g>

7 The <text> Element

<svg viewBox="0 0 200 60" width="200" height="60">
  <text x="10" y="40"
        font-family="sans-serif"
        font-size="24"
        font-weight="700"
        fill="#2563eb">
    Hello SVG
  </text>
</svg>

SVG text is real text — selectable, searchable, screen-reader accessible. Better than raster text for logos.

8 <defs> and <use>

Define reusable shapes or gradients in <defs> (not rendered directly), then reference them with <use href="#id"> wherever needed.

<svg width="200" height="80" viewBox="0 0 200 80">
  <defs>
    <symbol id="star" viewBox="0 0 24 24">
      <polygon points="12,2 15,9 22,9 17,14 19,22 12,18 5,22 7,14 2,9 9,9"
               fill="currentColor" />
    </symbol>
  </defs>

  <use href="#star" x="10"  y="20" width="40" height="40" style="color:#f59e0b" />
  <use href="#star" x="80"  y="20" width="40" height="40" style="color:#dc2626" />
  <use href="#star" x="150" y="20" width="40" height="40" style="color:#16a34a" />
</svg>
Pro tip — icon system pattern Define all icons as <symbol> in a hidden SVG at the top of the page, then reference each by <use href="#icon-search"> everywhere. One source of truth, infinite re-use, easy theming via currentColor.

9 Linear & Radial Gradients

<svg width="300" height="100" viewBox="0 0 300 100">
  <defs>
    <linearGradient id="lin" x1="0" y1="0" x2="1" y2="0">
      <stop offset="0%"  stop-color="#2563eb" />
      <stop offset="100%" stop-color="#7c3aed" />
    </linearGradient>
    <radialGradient id="rad" cx="0.5" cy="0.5" r="0.5">
      <stop offset="0%"   stop-color="#fbbf24" />
      <stop offset="100%" stop-color="#dc2626" />
    </radialGradient>
  </defs>

  <rect x="10"  y="10" width="120" height="80" fill="url(#lin)" rx="8" />
  <circle cx="220" cy="50" r="40" fill="url(#rad)" />
</svg>

11 Styling SVG with CSS

Inline SVG inherits from CSS like any other HTML element. The magic word is currentColor — it tells SVG shapes to inherit text color.

/* CSS */
.icon {
  width: 24px;
  height: 24px;
  stroke: currentColor;
  fill: none;
  stroke-width: 2;
}
.icon:hover { color: #7c3aed; }

/* HTML */
<a href="/" class="nav-link">
  <svg class="icon" viewBox="0 0 24 24">
    <path d="M3 12 L12 3 L21 12 M5 10v11h14V10" />
  </svg>
  Home
</a>
Pro tip — fill vs stroke Use stroke="currentColor" with fill="none" for outline icons (Feather, Lucide, Heroicons outline). Use fill="currentColor" for filled icons (Material, Font Awesome solid). Don't mix in the same icon set.

12 Common Mistakes

MistakeWhy it's badFix
Forgetting viewBoxSVG can't scale responsivelyAlways set viewBox
Hardcoding width/height without viewBoxDistorts when CSS resizesSet viewBox; control render size via CSS
Using fixed fill="#xxx" on iconsCan't theme via CSSUse currentColor + color in CSS
No <title> or aria-labelScreen readers see nothingAdd accessibility text
Inlining huge SVGs unoptimizedBloats HTML, slow first paintRun through SVGO; consider external file
Using xlink:href on <use>Deprecated; use plain hrefSwitch to href
Skipping xmlns on standalone SVG filesRenders as XML, not imageAlways include xmlns for .svg files
Inkscape/Illustrator export garbageIncludes sodipodi, inkscape namespacesRun SVGO or clean up export

13 Try It Yourself

Exercise 1 — Basic shapes Recreate a smiley face: a yellow circle (face), two small black circles (eyes), and a path for the smile. Use only <circle>, <path>, and fill.
Exercise 2 — Icon system Design 4 icons as <symbol> definitions in a hidden SVG at the top of a page. Use each one 3 times with <use> at different sizes and colors via currentColor.
Exercise 3 — Gradient logo Build a logo with: a circle filled with a <linearGradient>, an inner shape (checkmark, leaf, lightning bolt) in white, and SVG text next to it. Verify the text is selectable.
Exercise 4 — CSS-themable icon button Build a button with an SVG icon and a text label. The icon should change color on hover using only CSS — set stroke="currentColor" on the path, set color on the button, and change color on :hover.

14 Summary

  • Inline SVG = vector graphics embedded directly in HTML — scalable, scriptable, CSS-stylable.
  • Always set viewBox; control rendered size via CSS.
  • Basic shapes: <rect>, <circle>, <ellipse>, <line>, <polyline>, <polygon>.
  • <path> with d attribute draws anything — learn M, L, C, Q, A, Z commands.
  • <g> groups; <defs> + <use> enable reuse via symbol system.
  • Gradients via <linearGradient> / <radialGradient> with <stop> children.
  • Use currentColor + fill/stroke for CSS-themable icons.
  • Add <title>, <desc>, role="img", aria-label for accessibility.
